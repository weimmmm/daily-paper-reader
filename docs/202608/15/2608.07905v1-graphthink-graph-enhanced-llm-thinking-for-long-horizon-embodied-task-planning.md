## 摘要
使用基于LLM的规划器的具身代理常常面临物理幻觉、对长视界任务的泛化能力差以及缺乏环境意识的问题。我们提出了GraphThink，一个新颖的框架，它集成了任务图以提供结构化知识支持稳健规划，以及场景图以维护环境记忆用于事件驱动的重新规划。具体来说，任务图通过上下文提示和迭代细化引导LLM思考，有效缓解规划幻觉。此外，在GRPO框架内，任务图提供了精细的奖励设计来训练LLM规划器，增强长视界规划能力并改善泛化。最后，由场景图驱动的事件驱动重新规划模块实现了闭环环境感知和错误纠正。GraphThink在ALFRED基准上达到了最先进的性能。特别是，我们的高层规划器在验证集和保留的长视界任务上均超越了领先的基于API的LLM，突显了其稳健的零样本和少样本能力。额外的评估进一步证明了其对新颖任务和环境的强分布外泛化能力。

## Abstract
Embodied agents using LLM-based planners often struggle with physical hallucinations, poor generalization to long-horizon tasks, and lack of environmental awareness. We propose GraphThink, a novel framework that integrates a task graph to provide structured knowledge for robust planning and a scene graph to maintain environmental memory for event-driven replanning. Specifically, the task graph guides LLM thinking through contextual prompting and iterative refinement, effectively mitigating planning hallucinations. Furthermore, within the GRPO framework, the task graph offers delicate reward design to train the LLM planner, enhancing long-horizon planning capabilities and improving generalization. Finally, an event-driven replanning module, powered by the scene graph, enables closed-loop environment awareness and error correction. GraphThink achieves state-of-the-art performance on the ALFRED benchmark. In particular, our high-level planner surpasses leading API-based LLMs on both the validation set and held-out long-horizon tasks, underscoring its robust zero-shot and few-shot capabilities. Additional evaluations further demonstrate strong out-of-distribution generalization to novel tasks and environments.

- 论文聚焦于**基于 LLM 的具身智能体长视界任务规划**问题。在 ALFRED 这样的视觉-语言-交互基准中，智能体需要将自然语言指令分解为高层子任务，再由低层策略执行。

  1. **物理幻觉**：通用 LLM 缺乏物理世界常识，易产生不符合物体属性、操作前置条件的规划；
  2. **长视界泛化差**：监督微调依赖领域内数据，面对未见过的长视界任务时性能急剧下降；
  3. **环境感知缺失**：现有重规划策略多由低层执行错误触发，缺乏对“可执行但与指令意图不符”计划的识别与纠正能力。
- 论文核心含义：通过引入**任务图（Task Graph）** 和**场景图（Scene Graph）** 两种结构化知识表示，构建一个“双图增强的闭环规划系统” GraphThink，从根本上缓解上述问题，提升长视界具身规划的可靠性、泛化性与环境适应性。

## 2. 方法论

GraphThink 由三个核心模块组成：

### (a) 基于任务图的高层规划（High-Level Planning with Task Graph）

**任务图构建：**
- 任务图定义为有向图 \(G=(V,E)\)，节点 \(v_i\) 表示高层子任务，边 \((v_i,v_j)\) 表示子任务之间可行的转移关系。
- 节点通过元类抽象（obj、rec、mov、spec）泛化物体类别，提升跨环境泛化能力。
- 边的构建不依赖训练轨迹，而是通过 **LLM 辅助的转移兼容性分析**：将子任务抽象为转移接口 \(\langle P_i, E_i \rangle\)（前置条件与效果），当前序效果满足后序前置条件时建立有向边。
- 任务图可扩展性：新任务/新动作可通过同样的兼容性分析动态添加节点和边，无需新轨迹数据。

**任务图提示（Graph Prompt）：**
- 将任务图的节点和边编码为符号连接关系（如 `A→B`）显式嵌入 prompt，引导 LLM 生成的子任务序列遵循图拓扑，从而缓解规划幻觉。

**GRPO 训练与奖励设计：**
- 在 GRPO 框架下设计四类奖励：
  - **格式奖励 \(R_{\text{fmt}}\)**：XML/JSON 输出结构合规性；
  - **节点级奖励 \(R_{\text{node}}\)**：检查物体名是否属于环境物体集合，按元类动态加权；
  - **边级奖励 \(R_{\text{edge}}\)**：检查相邻子任务转移是否满足任务图边约束；
  - **指令跟随奖励 \(R_{\text{inst}}\)**：两阶段设计——覆盖关键子任务得 0.5，与 GT 计划完全匹配得 1.0，兼顾多解性与指令对齐。
  - 总奖励：\(R_{\text{total}} = R_{\text{fmt}} + R_{\text{node}} + R_{\text{edge}} + R_{\text{inst}}\)。

**任务图验证（Verification）：**
- 将任务图作为外部验证工具，在推理时对初始计划进行节点合法性验证和边合法性验证，将错误信息反馈给 LLM 进行迭代修正（最多 3 次），起到轻量级安全护栏作用。

### (b) 记忆感知的低层动作策略（Memory-Aware Low-Level Policy）

- 在低层执行中，主动缓存任务相关物体的位置与分割掩码，当路径上遇到其他任务相关物体时记录候选航点，减少重复探索。
- 对同类型多实例保持独立的交互记录，实现实例级区分，避免放置错误。

### (c) 基于场景图的事件驱动重规划（Dynamic Replanning with Scene Graph）

- **任务感知场景图记忆**：动态维护一个紧凑的场景图，只保留任务相关物体的语义三元组（如“on”“next to”），通过 VLM 从 RGB 图像和分割图提取候选三元组，并进行任务相关性过滤、物理合理性约束和冲突修正。
- **事件驱动重规划**，双触发机制：
  1. **低层动作错误**：如物体找不到、交互失败等，LLM 结合场景图记忆修正计划；
  2. **高层子任务完成**：在每个子任务完成时主动检查当前计划是否仍与最终指令一致，纠正“可执行但与目标不一致”的计划。
- 所有修正计划仍需通过任务图约束，保证可行性。

## 6. 主要结论与发现

- GraphThink 在 **ALFRED 测试集上达到 SOTA**：Tests Seen SR 67.71%、Tests Unseen SR 68.52%，均超过此前最优方法（如 EPO、RoboGPT 等）。
- **高层规划器表现突出**：在验证集 seen/unseen 和长视界任务上分别达到 96.22%、96.56%、90.04% 的规划成功率，显著超越 GPT-5.2、Gemini-2.5-Pro 等强 API 模型的各种提示策略。
- **任务图奖励是长视界泛化的关键**：缺少图奖励时，模型只能记忆训练集路径，长视界性能大幅下降（44.63%）；边级转移约束尤为重要。
- **事件驱动重规划有效**：低层错误触发和高层完成检查两个机制均带来显著增益，前者修正执行失败，后者纠正指令错位。
- **记忆感知低层策略提升执行稳定性**：避免重复探索和同实例误操作。
- **跨环境与跨任务泛化能力强**：ALFRED 训练的规划器可直接迁移到 VirtualHome 并保持竞争力；通过任务图扩展新动作可实现零样本新任务规划。

## 7. 优点

- **双图互补架构**：任务图提供“静态知识约束”，场景图提供“动态环境记忆”，二者在规划、训练、验证、重规划多个阶段协同，思路清晰且创新性强。
- **奖励设计优雅**：任务图将多解规划问题编码为结构化可行路径，结合指令奖励避免 reward hacking，解决了具身规划中 RL 奖励设计的核心难点。
- **事件驱动的双重重规划机制**：不仅处理低层执行错误，还能在高层子任务完成时主动检查语义对齐，弥补了现有方法“可执行但不正确”的盲区。
- **记忆感知低层策略务实有效**：主动缓存与实例级区分设计简单但实用，带来明确的性能提升。
- **实验非常全面**：覆盖基准 SOTA、组件消融、GRPO 细粒度消融、数据量影响、长视界、新任务、跨环境、推理效率等多维度，支持结论强度。
- **泛化性验证充分**：零样本/少样本、新动作原语、跨模拟器迁移均有实验支撑，说明方法具有实际应用潜力。

## 8. 不足与局限

- **算力资源未披露**：缺乏 GPU 型号、数量、训练时长等信息，复现成本无法准确评估。
- **任务图构建依赖 LLM**：边的生成基于 LLM 的转移兼容性分析，可能引入语义偏差；尽管附录声称验证了鲁棒性，但主文中未见对噪声边约束的详细分析。
- **场景图依赖 VLM 感知**：尽管有过滤和冲突修正机制，VLM 幻觉和感知错误仍可能潜入场景图，影响重规划质量。

- **评估方法潜在偏差**：长视界及跨环境实验中的成功率在部分情况下依赖 LLM 进行判断（当计划与 GT 不一致但符合图约束时），LLM 评判标准可能与真实任务完成情况存在偏差。
- **任务图扩展仍需人工/LLM 设计**：新增任务类型时需重新进行转移兼容性分析，框架的“自动化”程度受限于 LLM 分析质量。
- **同 API 模型对比的实际差距**：GraphThink 使用 7B 开源模型，但经历了任务图指导下的大规模 GRPO 训练；与 GPT-5.2 等闭源模型的对比可能未完全控制训练数据泄露或提示差异等混杂因素。
