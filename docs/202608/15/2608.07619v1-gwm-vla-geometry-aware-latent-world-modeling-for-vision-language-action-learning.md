## 摘要
视觉-语言-动作（VLA）模型在机器人操作任务中表现出色，但在视觉和环境变化下往往性能下降。潜在世界建模为提高鲁棒性提供了一种有前景的方法，但现有方法通常独立编码相机视角，并预测整体场景动态，而未显式建模其几何关系。我们提出了GWM-VLA，一种用于VLA学习的几何感知潜在世界建模框架。GWM-VLA结合了几何感知的多视角状态编码、全局上下文条件下的目标视角预测，以及由机器人动作监督驱动的共享潜在动作表示。具体而言，VGGT-$Ω$在每个时间步联合聚合多视角观测，以构建几何感知的多视角状态。潜在世界模型使用多视角聚合后得到的patch令牌和register令牌，预测选定目标视角的下一步patch令牌，从而在无需预测完整多视角状态的情况下保留多视角几何信息。在实验中，我们使用腕部视角作为目标，更加关注末端执行器运动和局部夹爪-物体交互。最后，共享的潜在动作表示同时条件化潜在世界模型和流匹配动作头，使得潜在预测监督和真实机器人动作监督能够共同塑造相同的潜在动作表示。在仿真和真实环境中的实验证明了GWM-VLA的有效性和鲁棒性。

## Abstract
Vision-Language-Action (VLA) models achieve strong robotic manipulation performance but often degrade under visual and environmental shifts. Latent world modeling offers a promising approach to improving robustness, yet existing methods commonly encode camera views independently and predict holistic scene dynamics without explicitly modeling their geometric relationships. We propose GWM-VLA, a geometry-aware latent world modeling framework for VLA learning. GWM-VLA combines geometry-aware multi-view state encoding, global context-conditioned target-view prediction, and shared latent-action representations grounded by robot-action supervision. Specifically, VGGT-$Ω$ jointly aggregates multi-view observations at each timestep to construct geometry-aware multi-view states. The latent world model predicts the next-step patch tokens of a selected target view using patch and register tokens obtained after multi-view aggregation, thereby retaining multi-view geometric information without predicting the complete multi-view state. We use the wrist view as the target in our experiments, placing greater emphasis on end-effector motion and local gripper-object interactions. Finally, the shared latent-action representations condition both the latent world model and the flow-matching action head, allowing latent-prediction supervision and ground-truth robot-action supervision to jointly shape the same latent-action representations. Experiments across both simulation and real-world environments demonstrate the effectiveness and robustness of GWM-VLA.

  - 潜在世界模型（如 VLA-JEPA）预测未来视觉潜在表示，更紧凑，但通常独立编码每个相机视角，再通过拼接融合，**未显式建模跨视角几何关系**，导致视觉对应关系和场景结构信息隐式且不充分。

- **本文目标**：提出 GWM-VLA，将**几何感知的多视角状态编码**与**潜在世界建模**结合，使策略不仅关注外观，更能捕捉动作引起的几何状态变化，从而在分布内和分布外环境下均保持准确与鲁棒的操控性能。

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 总体框架

GWM-VLA 由三部分组成：

1. **几何感知多视角编码器**（基于 VGGT-$Ω$）；
2. **全局上下文条件下的目标视角预测**（潜在世界模型）；
3. **共享潜在动作条件化的流匹配动作头**（flow-matching policy）。

训练目标为联合优化：

\[
L = L_{action} + \lambda L_{wm}
\]

其中 \(\lambda=0.1\) 为默认世界模型损失权重。

### 2.2 几何感知多视角状态编码

- 在每个时间步 \(t\)，将多视角观测 \(\{I^v_t\}_{v=1}^V\) 整体输入**冻结**的 VGGT-$Ω$ 编码器，进行联合聚合：

\[
\{R_t, P_t\} = E_\Omega(\{I^v_t\}_{v=1}^V)
\]

- \(R_t\)、\(P_t\) 分别为 register tokens 和 patch tokens。
- 不同时间步独立处理，同一时间步的所有视角联合编码，从而获得**跨视角几何关系感知**的潜在状态。

### 2.3 全局上下文条件下的目标视角预测

- 不预测完整多视角状态，而是选择一个目标视角 \(v^\star\)（实验中为**腕部视角**），仅预测该视角的 patch tokens：

\[
r_t = R_t^{v^\star}, \quad p_t = P_t^{v^\star}
\]

- 其中 \(p_t\) 为待预测的目标视角潜在状态，\(r_t\) 作为**全局几何上下文**注入潜在世界模型。由于 \(r_t\) 和 \(p_t\) 均来自多视角联合聚合，因此即使只预测单一视角，仍能利用全局多视角几何信息。
- 潜在世界模型 \(F_\phi\) 以目标视角 patch tokens、register tokens 和共享潜在动作序列 \(A_{0:T-1}\) 为条件，预测下一步 patch tokens：

\[
\hat{p}_{1:T} = F_\phi(p_{0:T-1}, r_{0:T-1}, A_{0:T-1})
\]

- 网络采用**时间因果注意力**，同一时间步内 token 可双向交互，跨时间步只能关注过去，注意力 mask 为：

\[
M_{ij} = \begin{cases} 0, & \tau(j) \le \tau(i) \\ -\infty, & \tau(j) > \tau(i) \end{cases}
\]

- 训练时采用 **teacher forcing**，下一步预测的监督目标由同一几何编码器编码真实未来多视角观测得到：

\[
p_{t+1} = E_\Omega^{P,v^\star}(O_{t+1})
\]

- 世界模型损失为 \(\ell_1\) 潜在预测误差：

\[
L_{wm} = \frac{1}{T}\sum_{t=0}^{T-1}\|\hat{p}_{t+1} - p_{t+1}\|_1
\]

### 2.4 统一潜在动作表示

- 采用 Qwen3-VL-2B 作为视觉-语言骨干，插入按时间步分组的可学习潜在动作查询 tokens \(Q_A\)。
- 由当前观测 \(O_0\) 和语言指令 \(\ell\) 生成潜在动作序列：

\[
A_{0:T-1} = Q_\theta(O_0, \ell, Q_A)
\]

- 与 VLA-JEPA 引入额外 embodied action 查询不同，GWM-VLA **直接复用**同一潜在动作序列同时条件化世界模型和动作头，使潜在预测与真实动作监督共同塑造相同的潜在动作表示，增强其与机器人控制的耦合。

### 2.5 条件流匹配动作头

- 使用条件流匹配（conditional flow matching）生成连续动作块，以共享潜在动作序列 \(A_{0:T-1}\) 和当前本体感受状态 \(s_0\) 为条件。
- 优化目标：

\[
L_{action} = \mathbb{E}\left[\left\|v_\psi(u_\gamma, \gamma \mid A_{0:T-1}, s_0) - (u_{0:T-1} - \epsilon)\right\|_2^2\right]
\]

其中 \(u_\gamma = (1-\gamma)\epsilon + \gamma u_{0:T-1}\)，\(\epsilon \sim \mathcal{N}(0,I)\)，\(\gamma \sim U(0,1)\)。

- 世界模型损失仅作为训练时的辅助目标，**部署时不使用**。

## 3. 实验设计

### 3.1 数据集与预训练

- **DROID**：大规模带动作标注的机器人数据集，约 76,000 条演示轨迹，覆盖多种任务、相机视角、工作台布局和视觉背景，用于预训练。
- **LIBERO**：仿真基准，含四个任务套件（Spatial、Object、Goal、LIBERO-10），作为分布内评估。
- **LIBERO-Plus**：LIBERO 的鲁棒性扩展基准，含七种扰动维度（相机视角、机器人初始状态、语言指令、光照、背景、视觉噪声、物体布局），作为分布外评估。
- **真实世界**：SO-101 机器人，使用 LeRobot 部署栈，收集 100 条遥操作演示，覆盖五个训练任务；评估设置包括分布内（ID）、OOD 任务（物体-容器重新组合）和 OOD 物体布局。

### 3.2 对比方法

对比了多类代表性方法：

- 潜在动作类：LAPA、UniVLA、villa-X；
- VLA 类：OpenVLA-OFT、π0、π0-FAST、CoT-VLA、GR00T N1、π0.5；
- 世界模型类：WorldVLA、VLA-JEPA（不含人类视频预训练的版本作为最直接可比基线）。

### 3.3 主要实验结果

- **LIBERO**：GWM-VLA 平均成功率 97.1%，与 OpenVLA-OFT 并列第一，超过 VLA-JEPA（96.1%）1.0 个百分点。
- **LIBERO-Plus**：平均成功率 76.9%，为目前最优，比 OpenVLA-OFT 高 7.3%，比 VLA-JEPA 高 14.0%；在语言、光照、物体布局扰动下排名第一，在相机视角、机器人初始状态、背景扰动下排名第二。
- **真实世界**：GWM-VLA 在 ID 和 OOD 布局设置下表现最佳，平均成功率最高；在 OOD 任务设置下达到 53.3%，超过 π0（26.7%）但低于 π0.5（60.0%）。

## 6. 主要结论与发现

- 几何感知多视角状态 + 潜在世界建模可以显著提升 VLA 在视觉与分布偏移下的鲁棒性，而对分布内性能几乎无损。
- 选择**腕部视角**作为预测目标效果优于第三人称视角，因为腕部视角与末端执行器运动和局部夹爪-物体交互更直接相关。
- 使用 **VGGT-$Ω$ 较深层的特征**（Layer 24）作为潜在状态效果最佳，说明更精细的几何表示有助于动态预测。
- **直接复用潜在动作 token** 同时条件化世界模型和动作头，优于引入额外 embodied query，说明共享潜在动作表示能更有效地耦合预测学习与动作控制。
- 预测的潜在状态定性上保留了场景布局和几何结构，但细节平滑。
- 真实世界实验表明，在有限演示下，几何感知预测为空间鲁棒性提供了有效归纳偏置；但**组合性指令泛化（OOD 任务）仍是独立挑战**，GWM-VLA 在该维度上不如 π0.5。

## 7. 优点

- **方法设计新颖且合理**：首次将几何基础模型 VGGT-$Ω$ 的联合多视角表示用作潜在世界模型的预测状态，显式建模了跨视角几何关系。
- **预测目标选择巧妙**：只预测单一目标视角 patch tokens，避免预测完整多视角状态的冗余计算，同时通过 register tokens 保留全局几何上下文，兼顾效率与信息量。
- **共享潜在动作表示**：统一了世界模型预测与动作生成两个目标，简化了模型结构并增强了表征一致性。
- **实验体系完整**：覆盖分布内、分布外、真实世界三大场景；包含多种方法对比、消融与定性分析，验证较充分。
- **结果突出**：在 LIBERO-Plus 上较当前最优方法提升 7.3%，较直接基线提升 14.0%，鲁棒性优势显著。
- **写作清晰**：对动机、方法、与 VLA-JEPA 的机制差异交代清楚，图 1 的对比直观。

## 8. 不足与局限

- **依赖多视角观测**：GWM-VLA 需要同一时间步的多视角输入来构建几何感知状态，限制了其直接适用于大规模人类视频预训练（通常只有单视角视频）。这是论文自我指出的主要局限。
- **固定目标视角**：训练中使用固定的目标视角（腕部），但最优目标视角可能随任务和传感器配置变化，缺乏自适应性。
- **OOD 任务泛化有限**：在真实世界 OOD 任务（物体-容器重新组合）上低于 π0.5，说明组合式指令泛化与空间鲁棒性是不同维度的能力，GWM-VLA 尚未完全解决前者。
