## 摘要
多智能体强化学习（MARL）是解决复杂协作任务的强大框架，但它在很大程度上依赖于定义良好的全局奖励函数。设计这样的奖励函数具有挑战性，尤其是在异构智能体系统中，单一标量目标可能无法捕捉多样化的行为。在本文中，我们引入了多智能体偏好集成学习（MAGPIE），通过智能体特定的偏好建模来应对这些挑战。每个智能体由专门的专家通过偏好信号进行评估，从而无需全局评估。我们从理论上证明，优化这些去中心化的偏好会收敛到纳什均衡策略。为了将局部偏好整合为连贯的全局目标，我们根据偏好数据构建智能体特定的奖励模型，并通过单调聚合机制将它们组合在一起。我们进一步证明，优化该聚合奖励模型等同于训练纳什均衡策略。在基准多智能体任务和序列生产线任务上的大量实验表明，MAGPIE实现了与奖励工程基线相当的性能，展示了其在精确奖励工程不切实际的情况下促进策略学习的潜力。

## Abstract
Multi-agent reinforcement learning (MARL) is a powerful framework for solving complex collaborative tasks, but it relies heavily on well-defined global reward functions. Designing such rewards is challenging, especially in systems with heterogeneous agents, where a single scalar objective may fail to capture diverse behaviors. In this paper, we introduce Multi-AGent Preference-Integrated lEarning (MAGPIE), which addresses these challenges through agent-specific preference modeling. Each agent is evaluated by a dedicated expert through preference signals, eliminating the need for global evaluation. We theoretically prove that optimizing these decentralized preferences converges to a Nash equilibrium policy. To integrate local preferences into a coherent global objective, we construct agent-specific reward models from preference data and combine them via a monotonic aggregation mechanism. We further prove that optimizing this aggregate reward model is equivalent to training the Nash equilibrium policy. Extensive experiments on benchmark multi-agent tasks and a sequential production line task show that MAGPIE achieves performance comparable to reward-engineered baselines, demonstrating its potential to facilitate policy learning in scenarios where precise reward engineering is impractical.

## 1. 论文的核心问题与整体含义

多智能体强化学习（MARL）在协作任务中表现突出，但其性能高度依赖精心设计的全局奖励函数。在异构多智能体系统中，不同智能体具有不同角色、观测和动作空间，单一标量奖励难以刻画多样且复杂的团队行为，导致“奖励工程”困难甚至不可行。此外，现有基于偏好的MARL方法存在三个主要问题：

- **全局偏好评估负担过重**：专家难以评价包含多个异构智能体的完整团队轨迹；
- **隐含智能体同质性假设**：部分方法通过比较同一轨迹中不同智能体的贡献来产生偏好，这不适用于角色差异大的异构系统；
- **部分依赖真实奖励**：有些方法仍借助 ground-truth 奖励作为辅助监督，违背了消除奖励工程的初衷。

针对上述问题，论文提出 **MAGPIE（Multi-AGent Preference-Integrated lEarning）**，为每个智能体分配独立的“教师/专家”，通过智能体特定的偏好信号进行局部评估，再将这些局部偏好聚合为全局学习信号，从而在无需全局奖励函数的情况下训练多智能体协作策略。理论上证明了该方法能够收敛到纳什均衡策略，并在多个任务上验证了与奖励工程基线相当的性能。

## 2. 论文提出的方法论

### 核心思想
- 每个智能体 \(i\) 有一个专属教师，对轨迹片段对 \((\sigma^{(0)},\sigma^{(1)})\) 给出二元偏好 \(p_i\)（表示哪个片段更符合该智能体在团队中的角色与贡献）。
- 将“全局评价”分解为“智能体特定局部评价 + 单调聚合”，从而支持异构智能体，并降低人类认知负担。
- 利用偏好数据训练每个智能体的局部奖励模型 \(\hat{r}_i\)，再通过求和形式的单调聚合构造全局奖励 \(\hat{r} = \sum \hat{r}_i\)，供标准 MARL 算法（如 QMIX）使用。

### 关键理论与公式
论文构建了完整的理论框架，主要包括：

- **Assumption 1–4**：假设每个智能体存在定义良好的偏好（对称、一致、传递），有可靠教师提供反馈；存在真值全局奖励 \(r(s,A)\)；且局部偏好与全局回报提升方向一致。
- **Theorem 1**：在有限状态/动作空间下，通过迭代更新偏好改进每个智能体策略（Algorithm 1），最终收敛到纳什均衡（当片段长度 \(H \to \infty\)）。
- **Assumption 5–7 与 Lemma 1**：假设每个智能体存在潜在局部奖励 \(r_i(s,A)\)，全局奖励是单调聚合函数；加性聚合下，只要局部改进对整体的负效应有界（Assumption 7），聚合奖励的优化可保持全局目标。
- **Theorem 2**：若学习的局部奖励模型与教师偏好完全一致，则最大化聚合奖励 \(\hat r = \sum \hat r_i\) 的策略是真实全局奖励下的纳什均衡策略。
- **Theorem 3**：在足够偏好数据和充分覆盖下，基于 Bradley-Terry 模型 + 交叉熵损失训练出的奖励模型 \(\hat r_i\) 收敛到真实局部奖励（差一个仿射变换），并给出有限样本误差界。
- **Theorem 4**：有限样本下，学习到的奖励模型导致的策略是 \(\epsilon\)-纳什均衡，且 \(\epsilon = \frac{2n\epsilon_r(N)}{1-\gamma}\)，随样本数 \(N\to\infty\) 而趋于 0。
- **附录 Theorem 5**：在随机采样条件下，使用线性分解 Q 网络时，QMIX 更新过程会几乎必然收敛到最优 Q 函数，从而补全了实际算法的收敛性分析。

### 算法细节（Algorithm 2）
- 初始化各智能体的局部奖励模型参数、策略参数、经验池和偏好池。
- 每个环境步：智能体基于局部 Q 函数选择动作，执行联合动作后，用当前聚合奖励 \(\hat r = \sum_i \hat r_i\) 存储转移。
- 每 \(K\) 步执行一次偏好收集：为每个智能体从经验池采样 \(M\) 对片段，由规则式“教师”生成偏好标签，存入对应偏好池。
- 更新每个奖励模型，损失函数为：
  \[
  L_i = L_i^{\text{pref}} + \lambda L_i^{\text{reg}},
  \]
  其中 \(L_i^{\text{pref}}\) 为 Bradley-Terry 交叉熵损失，\(L_i^{\text{reg}}\) 为惩罚“局部偏好与全局聚合偏好不一致”的正则项。
- 更新聚合奖励后，对经验池中的奖励进行重标记；最后用 QMIX 的损失更新 Q 网络和混合网络。
- 额外引入**连续偏好收集**和**经验重标记**以提升样本效率。

## 3. 实验设计

### 基准任务与场景
1. **MPE（Multi-Agent Particle Environment）**：
   - `Simple-Spread`：3 个同构智能体覆盖多个地标并避免碰撞，测试信用分配；
   - `Simple-Speaker-Listener`：说话者（离散通信）与听者（移动）异构协作，测试异构角色偏好融合；
   - `Simple-Reference`：两个智能体各自只知道部分目标，需在部分可观测下隐式协同。
2. **定制“手机生产线”任务**：
   - 三段过程：SMT、Assembly（组装）、Test（测试），各由一个智能体调度；
   - 随机到达任务，缓冲区容量限制，处理速度与吞吐、能耗之间有权衡；
   - 奖励函数由完成数、溢出惩罚和能耗构成。

### 对比方法
- **QMIX with task reward（oracle）**：使用环境真实奖励的 QMIX，作为奖励工程上界；
- **MAPT**：基于全局偏好的 MARL 方法；
- **Global-PbRL**：学习单一全局奖励模型的 PbRL 基线；
- **MATD3 with task reward**：基于连续动作的奖励工程基线。

### 偏好生成方式
- 没有使用真实人类标注，而是根据每个任务/角色设计启发式规则自动生成偏好标签，每个智能体的教师只基于与其角色相关的指标打分。

### 实验设置
- 片段长度 H 在 MPE 任务上取 {3, 5, 10}，在生产线任务上取 {5, 10, 20}；
- Simple-Spread 额外测试 3~6 个智能体的扩展场景；
- 结果在多组随机种子（5 seeds）上取平均，报告中位数/均值与标准差。

## 6. 论文的主要结论与发现

- 通过理论分析证明，智能体特定偏好优化可以引导系统收敛到纳什均衡，且加性单调聚合对全局奖励的重建具有理论保证。
