## 摘要
强化学习通过评估从当前策略采样的轨迹来改进自动驾驶视觉-语言-动作（VLA）模型。组相对策略优化（GRPO）从每个 rollout 组内的奖励差异中学习。当所有采样的轨迹都较差时，这种相对信号可以对失败进行排序，但无法识别失败区域之外的行为。我们提出了 FIRE-VLA，一个失败知情的自我进化框架，将此类未解决的失败转化为下一策略的特权监督。低奖励、低多样性的组触发从相同模型的冻结轮次起始副本进行自蒸馏。教师和学生具有相同的参数规模，但只有教师能观察到隐藏的未来轨迹。监督遵循学生生成的前缀，并限制在答案 token 上，而 GRPO 对每个组保持活动。更新后的策略为下一轮提供教师，使得路由的失败分布随策略变化，而无需更大的外部教师。从相同的 Qwen2.5-VL-3B SFT 检查点开始，比较匹配学生的 rollout 和策略更新次数。在来自 150 个保留 nuScenes 场景的 6,019 个示例上，FIRE-VLA 保持了可比的单样本规划，将 G=4 的平均 L2 从 1.848 米降低到 1.500 米，并将评估持久失败率从 13.03% 降低到 11.20%。平均误差的减少主要源于罕见的严重 rollout，而非普通轨迹上的均匀改进。

## Abstract
Reinforcement learning improves autonomous-driving vision-language-action (VLA) models by evaluating trajectories sampled from the current policy. Group relative policy optimization (GRPO) learns from reward differences within each rollout group. When all sampled trajectories are poor, this relative signal can rank failures without identifying behavior outside the failed region. We introduce FIRE-VLA, a failure-informed self-evolution framework that converts such unresolved failures into privileged supervision for the next policy. Low-reward, low-diversity groups trigger self-distillation from a frozen round-start copy of the same model. Teacher and student have the same parameter scale, but only the teacher observes the hidden future trajectory. Supervision follows the student's generated prefix and is restricted to answer tokens, while GRPO remains active for every group. The updated policy supplies the teacher for the next round, allowing the routed failure distribution to change with the policy without requiring a larger external teacher. Starting from the same Qwen2.5-VL-3B SFT checkpoint, the comparison matches student rollout and policy-update counts. On 6,019 examples from 150 held-out nuScenes scenes, FIRE-VLA retains comparable single-sample planning, reduces G=4 mean L2 from 1.848 to 1.500 m, and lowers evaluation-persistent failure prevalence from 13.03% to 11.20%. The reduction in mean error arises mainly from rare severe rollouts rather than uniform improvement across ordinary trajectories.

# FIRE-VLA 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型将视觉感知、语言推理与可执行的驾驶行为（如轨迹生成）结合。监督微调（SFT）提供驾驶先验，强化学习（RL）进一步从策略自身采样的轨迹中改进策略。
- **问题**：广泛使用的组相对策略优化（GRPO）依赖同组内多个响应之间的奖励对比。当一组内所有轨迹都表现较差（"未解决失败组"）时，GRPO 只能对这些失败进行相对排序，无法提供足以脱离失败区域的行为引导——其缺陷在于**纠正信息不足**，而非 GRPO 梯度消失或目标失效。
- **现有方案**：已有工作尝试通过失败精炼或特权蒸馏来补充信息，通常需要更大规模的外部教师模型。
- **核心问题**：能否让同一个 VLA 模型利用自身未解决的失败来监督其后续版本，避免引入更大的外部教师？

## 2. 方法论：FIRE-VLA

### 2.1 核心思想
- 将低奖励、低多样性（"未解决"）的 rollout 组路由到**特权自蒸馏**（PSD），同时**保留 GRPO 作为所有组的通用目标**。
- 使用**冻结的轮次起始策略副本**作为教师，教师与学生的参数规模相同，唯一区别是教师能访问**隐藏的真实未来轨迹**。
- 监督只作用于学生生成的**回答 token**，且沿学生自身的 on-policy 前缀进行，避免 off-policy 失配。
- 每轮结束后，更新后的策略成为下一轮的教师，使失败分布随策略演化而改变，无需外部模型。

### 2.2 关键技术细节

#### 奖励与 GRPO
- 轨迹奖励为：`r = 1 / (1 + (1/6) Σ ||p_t - p*_t||²)`，无效响应奖励为 0。
- GRPO 在组内对奖励做标准化得到优势 ˆA，并使用裁剪策略目标；该目标对所有组始终有效。

#### 失败路由（Failure-Informed Routing）
- 对每个组计算奖励均值 r̄、组内标准差 σ、有效样本比例 v。
- 训练时使用**批量相对阈值**（均值和标准差的 30% 分位数，有效性 ≥ 0.5）判定"未解决失败组"：
  - `r̄ ≤ Q₀.₃(r̄) ∧ σ ≤ Q₀.₃(σ) ∧ v ≥ 0.5`
- 未路由的组仅用 GRPO；路由的组额外添加 PSD（λ=0.1）。

#### 特权上下文
- 学生上下文：`(图像, 历史, 学生生成前缀)`
- 教师上下文：`(图像, 历史, ⟨priv⟩真实未来轨迹⟨/priv⟩, 学生生成前缀)`
- 教师冻结、无梯度；学生输入确保无特权 token；部署时只保留学生分支。

#### 答案 token 蒸馏
- 在每条响应前缀上计算学生与教师的分布差异（教师 top-16 token + 残差桶），使用**对称化 Jensen-Shannon 散度**（混合系数 β=0.5），并对每个 token 的散度设上限 0.05。
- 按"回答问题 token"加权聚合，而非按 rollout 均权；格式无效但仍有明确答案跨度的响应也参与。
- 完整损失：`L = L_GRPO + λ · 1[有路由组] · L_PSD`。

#### 轮次式自我进化
- 流程：`Unresolved(π_k) → 特权监督 → π_{k+1} → Unresolved(π_{k+1})`
- 实验采用 K=2 轮，每轮 75 次策略更新。

## 3. 实验设计

- **基础模型**：Qwen2.5-VL-3B-Instruct 的 SFT 检查点（同一初始化）。
- **数据集**：nuScenes；训练用 1,200 个唯一 RL prompt，每方法 4,800 次学生 rollout、150 次策略更新。
- **评估集**：150 个与训练/微调场景无关的保留场景，共 6,019 个固定样本。
- **评估协议**：
  - 单样本低温规划（温度 0.2）
  - G=4 随机采样（温度 0.8），组内候选先按样本平均再跨样本平均
  - 所有 GRPO 与 FIRE-VLA 对比均按样本配对，使用 10,000 次场景聚类 bootstrap 计算置信区间
- **对比方法**：仅对照标准 GRPO（从相同 SFT 检查点，连续 150 次更新）；另有共同的 SFT 参考作为基线。

## 4. 资源与算力

- 训练硬件：4 张 RTX 3090 GPU，全参数 BF16 训练，使用 FSDP。
- 其他配置：学习率 5×10⁻⁷，权重衰减 10⁻²，全局 batch size 8，响应上限 384 token。
- 文中明确说明：FIRE-VLA 额外付出**冻结教师前向计算**，且第二轮重启优化器/调度器状态；因此**并非等计算量对比**。训练时长未具体给出。

### 实验数量

- 分布统计：候选 P90/P95/P99、CVaR95/CVaR99、最差候选平均、组内标准差、>"10 m" 概率、winsorized 均值差异。
- 消融/组件隔离：**未进行**（文中承认端到端对比未分离失败路由、特权蒸馏、教师轮次提升各自贡献）。

### 充分性与公平性
- **公平性**：训练初始化、唯一 prompt 集合、rollout 数、更新次数均匹配；但 **minibatch 顺序不同**，且 FIRE-VLA 计算成本更高，非等计算对比。
- **客观性**：评估集场景不重叠；持久失败检测器在独立 SFT 校准集上冻结，未针对 GRPO/FIRE 重新校准；置信区间采用场景聚类 bootstrap。
- **不足**：每种方法只有**一条训练种子**，无法估计训练随机性；仅两轮演化，未证明更多轮的单调改进；未做组件消融。

## 6. 主要结论与发现

- **单样本规划**：FIRE-VLA 数值上略优（Avg. L2 0.602 vs 0.642 m），但配对置信区间跨零，结论为**可比而非显著优势**。
- **G=4 随机规划**：平均 L2 从 1.848 m 降至 1.500 m（降 18.8%），配对差异 -0.3476 m，95% CI [-0.7711, -0.0319]，**显著**。
- **持久失败率**：评估持久失败从 13.03%（784/6019）降至 11.20%（674/6019），配对差异 -1.83 个百分点（CI [-2.55, -1.11]）。
- **严重尾部**：至少一个候选超过 10 m 的样本从 1.35% 降至 0.83%；CVaR95/CVaR99 均显著下降；但候选 P90/P95 反而 GRPO 更优。
- **主要机制**：平均误差降低**主要来自抑制罕见严重 rollout**，而非对普通轨迹的均匀改进；winsorized 分析确认了这一点。
- **恢复率**：对 SFT 参考持久失败集，GRPO 恢复 23.35%，FIRE-VLA 恢复 25.21%，差异不显著。
- **奖励-几何差异**：GRPO 的平均奖励更高（0.637 vs 0.616），但 L2 尾部更重，原因在于奖励的倒数变换在严重错误处饱和。

## 7. 优点

- **方法设计新颖**：将"未解决失败组"作为路由信号，将相对奖励不足与特权蒸馏自然结合，无需外部大教师。
- **自演化机制**：轮次式教师晋升使失败分布随策略漂移，更贴合 on-policy 特性。
- **监督精准**：仅在学生生成前缀上的回答 token 处进行蒸馏，减少 off-policy 失配；GRPO 始终保留，不牺牲原有学习信号。
- **评估严谨**：冻结评估集、场景聚类置信区间、独立校准的持久失败检测器、配对分析、winorized 稳健性检查，统计证据较为扎实。
- **透明度**：公开代码、配置、评估协议与数据来源。

## 8. 不足与局限

- **实验覆盖有限**：仅一条训练种子；仅两轮演化；未做组件消融（路由、蒸馏、轮次提升分别贡献不明确）。
- **非等计算对比**：FIRE-VLA 额外教师前向、优化器/调度器重启，算力成本更高，结论不适用于"同样算力"场景。
- **评估范围局限**：仅前视摄像头、开环轨迹评估；未评估闭环安全、交通法规遵守、舒适性、复合状态漂移。
- **训练不纵向追踪**：两轮使用不相交的 prompt 子集，无法追踪同一 prompt 的跨轮演化。
- **性能边界**：单样本优势不显著；G=4 的普通分位（P90/P95）反而劣于 GRPO；对 SFT 参考失败的恢复率无显著提升；RL 本身相比 SFT 仍增加了随机 L2 误差，FIRE-VLA 只是部分缓解。
- **潜在偏差风险**：定性图选取虽固定协议，但仍有人工筛选成分；恢复率检测器为单点阈值，可能掩盖更细粒度变化。
