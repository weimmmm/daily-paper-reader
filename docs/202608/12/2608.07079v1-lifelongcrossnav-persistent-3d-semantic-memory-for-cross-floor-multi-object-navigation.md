## 摘要
物体目标导航在语义感知和探索方面取得了显著进展，但用于多目标导航和跨楼层导航的持久记忆仍然通常被分开处理。我们提出了LifelongCrossNav，一个用于未知多楼层室内环境中顺序多目标导航的框架。在每个回合中，智能体接收有序的物体目标查询序列，同时持续维护一个共享的稀疏3D语义体素记忆。该记忆逐步积累几何结构、可穿越状态和视觉-语言特征，使得后续的物体目标查询能够检索之前获取的场景信息，而无需重建地图。为了支持跨楼层的持久搜索，LifelongCrossNav结合了支持感知的3D可穿越性映射、楼梯特定感知和方向感知的楼梯穿越。一个统一的导航策略协调同层前沿探索、实时和历史兴趣点检索、楼梯导航以及目标搜索和接近。我们进一步引入了HM3D-MFMON，一个基于HM3D场景构建的顺序多楼层多目标导航基准，包括一个专门的子集，其中完成完整的物体目标子任务序列需要至少一次楼层转换。实验结果表明，LifelongCrossNav在HM3D-MFMON上始终优于具有代表性的平面持久语义地图基线，证明了持久3D语义记忆和跨楼层可穿越性建模能够有效支持多楼层环境中的顺序多目标导航。项目页面：https://flageval-baai.github.io/LifelongCrossNavPage。

## Abstract
Object-goal navigation has made substantial progress in semantic perception and exploration, yet persistent memory for multi-object navigation and cross-floor navigation are still commonly addressed separately. We present LifelongCrossNav, a framework for sequential multi-object ObjectNav in unknown multi-floor indoor environments. Within each episode, the agent receives an ordered sequence of object-goal queries while continuously maintaining a shared sparse 3D semantic voxel memory. This memory incrementally accumulates geometric structure, traversability states, and vision-language features, allowing subsequent object-goal queries to retrieve previously acquired scene information without rebuilding the map. To support persistent search across floors, LifelongCrossNav combines support-aware 3D traversability mapping, stair-specific perception, and direction-aware stair traversal. A unified navigation policy coordinates same-floor frontier exploration, live and historical point-of-interest retrieval, stair navigation, and target-object search and approach. We further introduce HM3D-MFMON, a benchmark for sequential Multi-Floor Multi-Object Navigation built on HM3D scenes, including a dedicated subset in which completing the full sequence of object-goal subtasks requires at least one floor transition. Experimental results show that LifelongCrossNav consistently outperforms a representative planar persistent semantic-map baseline on HM3D-MFMON, demonstrating that persistent 3D semantic memory and cross-floor traversability modeling effectively support sequential multi-object navigation in multi-floor environments. ## 2. 论文提出的方法论

### 2.1 整体框架概览
LifelongCrossNav 是一个闭环系统，由三大核心模块构成：
1. **支持感知的 3D 体素建图**（Support-Aware 3D Voxel Mapping）；
2. **持久 3D 语义记忆**（Persistent 3D Semantic Memory）——存储目标无关的视觉-语言特征；
3. **统一导航策略**（Unified Navigation Policy）——协调同层探索、楼梯穿越、语义检索和目标接近。

### 2.2 支持感知的 3D 体素建图
- **RGB-D 反投影与稀疏体素化**：有效深度像素经相机内外参变换到世界坐标系，量化为稀疏体素；深度射线的端点为表面证据，中间位置为自由空间证据。
- **四种功能体素类型**：
    | 体素类型 | 含义 |
    |---|---|
    | **Occupied** | 观察到的表面（墙壁、家具、地板、未确认楼梯候选） |
    | **Traversable** | 有可靠支撑的自由空间（向下搜索 0.40m 范围内有支撑） |
    | **Unsupported** | 自由空间但未观察到支撑，为潜在下降过渡提供证据 |
    | **Stair** | 经过语义与几何联合确认的楼梯表面 |
- **楼梯验证**：SegFormer-B2 提取像素级楼梯掩码，通过深度和位姿提升至 3D，并用**局部高度变化、台阶趋势、空间连续性和支撑关系**进行验证；只有在进入 Stair Explore 模式后才确认更新。

### 2.3 持久 3D 语义记忆
- **密集视觉-语言特征编码**：采用 SED 编码器，生成 24×24×768 的特征图（与 CLIP 文本嵌入空间对齐），双线性上采样至深度分辨率，并与每个有效深度像素关联。
- **特征提升与累积融合**：像素特征仅分配到观察到的表面体素，不传播至自由空间。多视角观察采用**累积加权平均**融合（公式 1 和 2）：
  - 帧内聚合：f̄_v = Σ qₚfₚ / Σ qₚ + ε
  - 跨帧累积：F_v^(t) = (C_v^(t-1)F_v^(t-1) + c_v^(t)f̄_v^(t)) / (C_v^(t-1) + c_v^(t))，C 为置信度累积。
- **查询条件 3D 检索**：当新的物体目标激活时，其文本嵌入与存储的表面体素特征计算余弦相似度，形成查询条件化 3D 相似场；高响应区域经 3D 邻域聚类，取 Top-K 候选作为 **History POIs**。

### 2.4 统一导航策略
- **候选导航点**分为四类：
    - **Basic Frontiers**：Traversable Frontiers（可穿越与未知边界）、Descend Frontiers（可穿越与无支撑边界，指示潜在下降）、Ascent Frontiers（楼梯语义-几何证据产生的上升入口）；
    - **Stair Frontiers**：从已确认 Stair 体素簇提取的方向感知前进边界，高度随观察到的楼梯变化；
    - **History POIs**：通过查询持久语义记忆获得；
    - **Live POIs**：通过检测器实时生成（YOLOv7 覆盖 HM3D 六类，YOLO-World 处理开放词汇）。
- **分层模式切换**：
    - 可靠的当前目标证据与可达 POI 优先级最高；
    - 无有效语义候选时，Basic Explore 先探索当前楼层的 Traversable Frontiers，再考虑 Descend/Ascent；
    - 楼梯入口验证后进入 **Stair Explore**，该模式持续控制直至到达新平台；
    - 所有模式共用 3D A* 规划器，但**可通行体素类型和图连接性**不同（普通 26 邻域图 vs. 楼梯模式 1.0m 球邻域）。
- **最终目标接近与验证**：检测掩码投影到 3D，选择安全观察位置；接近过程中根据检测置信度、掩码质量、可见性、视角和 3D 距离进行验证；只有通过验证才完成子任务。

## 6. 论文的主要结论与发现

1. **持久 3D 语义记忆 + 跨楼层建模有效**：LifelongCrossNav 在全部 927 回合和 288 个 CFR 回合上，序列级 SR/SPL/PR/PPL 均优于 OneMap（例如全集 SR 达 29.13% vs 16.83%，CFR 子集 SR 达 7.99% vs 0.00%）。

2. **History POI 提升路径效率**：禁用 History POI 后，SPL 和 PPL 明显下降（全集 SPL 从 9.64 降至 8.46，PPL 从 16.70 降至 14.91），说明历史语义检索减少了重复探索，主要体现在**后续目标阶段**的路径效率提升上（条件 SPL 曲线显示 LifelongCrossNav 在 Goal 2、Goal 3 稳定增长，而 w/o H-POI 几乎不变）。

3. **跨楼层场景中平面记忆失效**：OneMap 在 CFR 子集上序列级 SR 为 0，无法解决必须的楼层转换；而 LifelongCrossNav 通过显式楼梯表示和跨楼层连通性取得了非零成功率。

4. **在单目标导航上保持竞争力**：SR（59.7%）优于 OneMap（55.8%），但 SPL（28.0%）低于 OneMap（37.4%），原因在于多楼层策略优先探索当前楼层后再激活跨楼层候选，可能增加路径开销。

5. **失败模式的转移**：History POI 减少了局部规划卡住和探索不充分的失败，但增加了误检失败——主要集中在床类别（与沙发视觉相似），导致验证失败。

## 7. 优点

### 7.1 方法设计亮点
1. **统一框架**：首次将持久语义记忆与跨楼层导航形式化地整合进一个闭环系统，而非割裂处理；
2. **目标无关的记忆设计**：语义特征以目标无关方式存储，新目标激活时仅需重新计算相似场，无需重建地图，计算高效；
3. **支持感知的体素建模**：区分 Occupied/Traversable/Unsupported/Stair 四种状态，保留垂直结构信息，能处理平面图中垂直重叠空间的问题；
4. **延迟确认的楼梯状态提升机制**：普通探索中收集的楼梯证据不会立即改变规划图，只有进入 Stair Explore 并经过验证后才提升为 STAIR，避免噪声干扰；
5. **模式感知的 3D 规划**：不同模式使用不同的可通行体素集合和图连接性（如楼梯模式的 1.0m 球邻域可处理稀疏观察），适应不同任务阶段的规划需求；
6. **开放词汇能力**：视觉-语言特征检索支持超出固定检测器标签集的语义查询。

### 7.2 实验设计亮点
1. **新基准填补空白**：HM3D-MFMON 是首个将多目标导航与跨楼层要求结合的基准；
2. **评估协议严谨**：事后分阶段最短路径协议有效避免了 oracle 偏差，条件/全局指标分离了"能否到达该阶段"和"到达到后能否成功"两个维度；
3. **丰富的分析视角**：包括整体性能、阶段条件性能、跨楼层子集、失败归因等多层次分析。

## 8. 不足与局限

### 8.1 实验覆盖局限
- **仿真环境为主**：所有实验在 HM3D 仿真场景中进行，未涉及真实世界部署验证；文中展望部分也承认"真实世界部署"是未来工作方向；
- **主实验对比方法较少**：多目标导航实验中仅对比了 OneMap 一个平面基线，未与其他 3D 方法（如 BeliefMapNav）或跨楼层方法（如 ASCENT、TravExplorer）在多目标设定下对比；
- **消融不完整**：仅消融了 History POI 一项，未针对 3D 表示本身、楼梯感知模块、支持感知分类等进行逐项消融，归因不够全面；
- **目标类别有限**：仅覆盖 HM3D 六类固定目标，虽然支持开放词汇检索，但未专门设计实验验证开放词汇场景下的多目标导航能力。

### 8.2 偏差与分析风险
- **SR 与 SPL 的权衡**：完整框架在全集上的 SR 略低于 w/o H-POI（29.13% vs 29.77%），论文将其归因于误检增加，但也反映出 History POI 检索可能引入噪声目标的固有风险；
- **单目标 SPL 较低**：在当前楼层优先策略下，SPL 显著低于 OneMap，若任务不跨楼层，该策略可能造成路径浪费；
- **失败分析中的误检集中在 bed**：说明检测器在相似类别（床/沙发）上的混淆未得到有效解决，语义记忆检索可能放大这一偏差。

### 8.3 应用限制
- **对楼梯结构的依赖**：方法依赖 SegFormer 对楼梯的语义分割和几何验证，在楼梯形态异常或分割失效的真实环境中可能退化；
- **地图范围有限**：地图 XY 范围 60×60m，索引 Z 范围约 ±30m，超出该范围的大规模场景不适用；
- **体素分辨率固定**：0.10m 体素分辨率在计算量与精细度之间取了折中，对细小目标或狭窄通道可能存在量化误差；
- **规划器启发式**：A*

### 8.3 应用限制（续）

- **规划器启发式（续）**：统一导航策略中的路径规划依赖 3D A* 搜索，采用启发式代价估计。在楼梯穿越和跨楼层规划中，该启发式主要基于几何距离，未显式建模上下楼梯的额外时间代价（如速度变化、转向开销），可能导致规划路径在几何上最短但实际执行效率并非最优；此外，A* 的搜索范围受地图边界和体素图约束，在大规模开放场景中计算开销可能显著增加。

## 9. 未来工作方向

### 9.1 真实世界部署与泛化
- 论文在展望中明确将**真实世界部署**列为首要未来方向；
- 需要解决仿真到真实的领域差距问题，包括：真实楼梯的语义分割鲁棒性、深度传感器的噪声与缺失、位姿估计漂移、以及动态障碍物（行人）的处理；
- 当前的体素建图与特征融合假设静态环境，真实场景中的人物移动可能破坏自由空间证据的可靠性。

### 9.2 表示与记忆机制的扩展
- **开放词汇多目标导航的系统性评测**：虽然方法支持 CLIP 文本嵌入检索，但论文未专门设计实验量化开放词汇目标（超出 HM3D 六类）下的检索精度和导航成功率，未来可构建更丰富的目标词汇表进行评测；
- **记忆的长期遗忘与压缩**：持久 3D 语义记忆随探索时间无限累积，如何在大规模长期任务中实现记忆的压缩、遗忘或抽象（如场景图表示）是重要的效率问题；
- **与显式拓扑图的融合**：当前基于体素的表示在几何细节上丰富，但缺乏高层次的空间关系推理；未来可与拓扑图或语义场景图结合，提升远距离目标推理能力。

### 9.3 策略与学习范式
- **端到端强化学习**：当前导航策略依赖人工设计的模式切换和启发式规则，未来可探索将跨楼层导航与多目标记忆纳入端到端 RL 框架，自动学习模式切换策略；
- **分层强化学习**：将同层探索、楼梯穿越、语义检索建模为高层选项（options），利用历史记忆作为状态输入，可能提升策略的泛化性；
- **多智能体协同**：在多楼层大规模场景中，多个智能体分别探索不同楼层并通过共享记忆协同导航，是值得探索的方向。

### 9.4 评估协议的进一步完善
- 当前基准 HM3D-MFMON 基于 HM3D 场景，目标类别和楼层结构存在一定局限性；
- 未来可扩展到更丰富的场景数据集（如多楼层真实扫描、建筑 BIM 模型），并引入**随机目标生成**以避免场景-目标组合的分布偏差；
- 评价指标可进一步引入**效率与安全性的权衡**（如楼梯穿越能耗、跌倒风险等），更贴近真实机器人应用需求。

## 10. 总体评价与定位

### 10.1 学术贡献定位
LifelongCrossNav 是**首个系统性地将持久 3D 语义记忆与跨楼层可穿越性建模整合进顺序多目标 ObjectNav**的工作。它的核心贡献不是单一算法模块的创新，而是**任务定义、问题拆解、系统设计、评测协议**四者相辅相成的整体方案：

1. **任务层面**：定义了多楼层顺序多目标导航任务，弥补了现有基准在垂直维度上的缺失；
2. **系统层面**：提出支持感知的 3D 体素建图、目标无关的持久语义记忆、统一模式切换策略三位一体的框架，各模块耦合度低、可替换性强；
3. **评测层面**：事后分阶段最短路径协议对顺序多目标任务具有普适参考价值，且条件/全局指标框架具有严谨的数学基础。

### 10.2 方法创新性评述
- **创新性中等偏上**：各子模块（体素建图、CLIP 特征检索、YOLO 检测、A* 规划）均为成熟技术，但论文的贡献在于**如何将它们有机组合**以解决此前被割裂的复合问题；
- **工程实现完整度高**：从感知、记忆、规划到验证的闭环系统具有高度的模块化和可复现性；
- **理论分析仍有提升空间**：论文对记忆融合的权重设计、模式切换的时机选择多依赖经验阈值，缺乏理论最优性分析。

### 10.3 局限性的综合评述
论文的主要弱点集中在**实验对比的充分性**和**消融的完整性**上。尽管 HM3D-MFMON 基准具有开创性，但主实验仅与 OneMap 对比，消融仅针对 History POI，这使得"持久 3D 语义记忆 + 跨楼层建模"这两个核心命题的**各自贡献无法被独立量化**。此外，单目标实验中 SPL 显著低于 OneMap，也反映出该方法在纯单目标任务中可能不是最优选择，其优势主要体现在**长序列·多目标·跨楼层**的复合场景中。

### 10.4 对领域的影响与启示
- 对**多目标导航**方向：论文明确了"目标无关的持久记忆"是避免重复探索的关键，后续工作可在此基础上探索更高效的记忆检索策略；
- 对**跨楼层导航**方向：三种功能体素（Traversable / Unsupported / Stair）的分类和延迟确认机制为处理楼梯等垂直结构提供了可借鉴的范式；
- 对**评估方法**：条件/全局双指标体系和事后分阶段最短路径设计，为其他顺序决策任务（如多目标抓取、多房间清洁）提供了评估设计的模板。

## 11. 总结

LifelongCrossNav 针对真实室内服务机器人面临的多楼层、多目标顺序导航需求，提出了一个融合持久 3D 语义记忆与跨楼层可穿越性建模的统一框架，并配套构建了 HM3D-MFMON 基准和事后分阶段评估协议。实验表明，该方法在序列级成功率、路径效率以及跨楼层强制场景中均优于现有平面基线，验证了核心命题的合理性；同时，消融与失败分析揭示了历史语义检索在减少重复探索方面的关键作用，也暴露了误检放大和单目标路径效率不足等问题。

论文的整体价值在于**问题定义的准确性与系统性**，而非单一算法的突破性创新。它为多楼层顺序多目标导航这一复合任务提供了首个可复现的基线、评测标准和参考架构，为后续研究奠定了良好的基础。然而，其仿真环境局限、对比方法不足和消融不完整等问题，也为后续工作留下了明确的改进空间。
