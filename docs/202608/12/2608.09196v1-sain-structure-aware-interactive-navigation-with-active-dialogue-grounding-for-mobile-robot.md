## 摘要
大多数现有的视觉-语言导航任务假设指令是完整且明确的。然而，现实世界中的机器人经常遇到模糊、不明确或不完整的自然人类指令，需要它们通过主动提问来解决这些不确定性。交互式实例目标导航（IIGN）要求具身代理通过主动对话，在模糊的类别级指令下找到具体实例。然而，现有的支持对话的方法通常将oracle答案作为即时决策的临时文本上下文，而不是持久的空间或对象中心的结构化状态。我们提出了SAIN，一个零样本框架，将主动对话转化为持久的导航状态。SAIN不是将oracle答案作为单步文本提示，而是将它们编译为目标证据、路线级走廊记忆和对象候选标签。这些状态存储在结构化的价值、房间、图和对象记忆中，然后由统一策略用于前沿排序和最终目标逼近。在VL-LN IIGN基准上，与最强的已报告的支持对话的基线相比，SAIN将SR从20.2提高到25.4，将SPL从13.07提高到14.17，且不需要特定于任务的策略训练。结果支持对话到状态的转换作为长视野交互式实例导航的有效零样本机制。项目网站：https://zorattc.github.io/SAIN/

## Abstract
Most existing vision-language navigation tasks assume that instructions are complete and unambiguous. However, real-world robots often encounter natural human instructions that are ambiguous, underspecified, or incomplete, requiring them to resolve such uncertainties through active questioning. Interactive Instance Goal Navigation (IIGN) requires an embodied agent to find the specific instance under an ambiguous category-level instruction through active dialogue. However, existing dialogue-enabled methods often consume oracle answers as transient textual context for immediate decisions, rather than persistent spatial or object-centric structured state. We present SAIN, a zero-shot framework that turns active dialogue into persistent navigation state. Instead of consuming oracle answers as one-step text hints, SAIN compiles them into target evidence, route-level corridor memory, and object-candidate labels. These states are stored in structured value, room, graph, and object memories, then consumed by a unified policy for frontier ranking and final target approach. On the VL-LN IIGN benchmark, SAIN improves SR from 20.2 to 25.4 and SPL from 13.07 to 14.17 over the strongest reported dialogue-enabled baseline, while requiring no task-specific policy training. The results support dialogue-to-state conversion as an effective zero-shot mechanism for long-horizon interactive instance navigation. Project website: https://zorattc.github.io/SAIN/

- **核心问题**：论文聚焦于交互式实例目标导航（IIGN）任务，该任务要求机器人在模糊的类别级指令下，通过主动向人类/Orcale提问，逐步消除**实例不确定性**（哪个具体目标）和**探索不确定性**（目标可能在哪个未探索区域），最终定位到用户意图的特定实例。
- **现有方法不足**：已有对话式导航方法往往将oracle的回答作为**瞬时文本上下文**用于当前决策，而非持久化的空间或对象中心的**结构化状态**。这使得语言反馈在机器人移动到新区域后失去引导作用，难以支撑长时程导航。
- **论文含义**：作者提出**对话到状态（dialogue-to-state）**原则，即把对话回答编译为持久的内部导航状态（目标证据、路线走廊记忆、候选标签等），以支持地图构建、候选推理与长时间导航决策——这是解决长时程交互式实例搜索的关键机制。

## 2. 论文提出的方法论

### 2.1 核心思想

- **SAIN** 是一个零样本（zero-shot）框架，无需任务特定的策略训练。
- 核心原则：**对话不直接转化为动作，而是转化为持久的结构化记忆状态**，由统一策略层消费这些状态进行导航决策。
- 整体记忆状态定义为：
  - **S_t = {V_t, G_t, R_t, O_t, F_tar, M_route_t, M_hist_t}**
  - 其中 V_t 是目标级语义价值图，G_t 是拓扑图，R_t 是房间级语义图，O_t 是候选对象图，F_tar 是从对话中积累的目标事实，M_route_t 和 M_hist_t 分别编码接地路线掩码和累积路线历史掩码。

### 2.2 关键模块与技术细节

1. **结构化地图表示（Structured Maps）**：
   - **价值图 V_t**：基于VLFM的BLIP-2匹配器对RGB视图打分并投影到全局地图，提供目标条件下的前沿探索先验。
   - **图地图 G_t**：从可探索自由空间骨架化出拓扑节点，暴露空间不确定性。
   - **房间图 R_t**：使用分水岭分割将空间划分为房间区域，VLM标注代表性视图并选择目标相关房间。
   - **对象图 O_t**：GroundingDINO + MobileSAM产生RGB-D掩码，反投影为全局3D点云，通过KD-tree距离关联保持实例一致性。

2. **目标感知与实例候选推理**：
   - **熵感知VQA过滤**：读取VLM在 {yes, no, I don't know} 上的next-token logits，计算熵 H_j；仅接受 y_j=yes 且 H_j < τ_H 的检测结果，抑制不可靠检测。
   - **基于相似度的实例验证**：VLM描述候选对象 → LLM将候选证据与目标事实转为验证三元组 Q_i → 保留确定答案进行证据精炼 → LLM相似度函数 s_i 打分 → 根据两个阈值 τ_low/τ_high 将候选标记为 REJECTED/PENDING/CONFIRMED。

3. **主动提问与对话状态更新**：
   - **信息问题（Information）**：在任务开始或目标事实不足时提出，回答被解析为目标事实，供候选评分和房间相关性使用。
   - **路线问题（Route）**：在未查询过的分支节点且无确认候选时提出，回答被接地到图路径。
   - **消歧问题（Disambiguation）**：对近距离稳定的 PENDING 候选提出，yes/no 回答将候选更新为 CONFIRMED/REJECTED。

4. **路线接地探索与导航策略**：
   - **路线回答接地**：从最近图节点做有界深度优先搜索，分支均衡选择路径候选，LLM匹配器（LMMatch）将路线回答与路径描述匹配，选出最合适路径。
   - **路线掩码与前沿打分**：
     - 短期路线掩码：M_route_t(x) = 1 + β_r exp(-dist(x,C*_t)²/2σ_r²)
     - 长期历史掩码：M_hist_t(x) = 1 + H_t(x)，其中 H_t = γH_{t-1} + β_h exp(-dist(x,C̄*_t)²/2σ_h²)
     - 房间先验：M_room_t(x) = 1 + β_room 1[x ∈ R*_t]
     - 最终前沿得分：s(ξ) = s_val(ξ) · m_route(ξ) · m_hist(ξ) · m_room(ξ)
   - **目标导向执行**：PENDING 候选时转向候选附近验证；CONFIRMED 后执行 PointGoal 导航直接逼近目标。

## 6. 论文的主要结论与发现

1. **对话到状态转换是有效的零样本机制**：SAIN将对话回答编译为持久状态后，在不进行任务专项训练的情况下，SR从20.2提升至25.4，SPL从13.07提升至14.17，NE从8.84降至8.06，全面超越最强的对话式基线VLLN-D。
2. **第一条信息问题是边际收益最大的对话**：SAIN-D1（仅一次信息问题）达到20.6 SR，MSP高达9.00，接近学习型对话基线VLLN-D（20.2 SR）而只用了1个问题。
3. **路线记忆是最强的空间先验**：去掉路线奖励导致SR从25.4降至19.0，是所有消融中下降幅度最大的。
4. **持久实例状态比仅到达目标区域更重要**：去掉相似度验证器后OS升至70.0但SPL降至11.02，说明"到达过目标区域"不等于"成功确认目标"。
5. **对话减少了错误检测但歧义仍是主要瓶颈**：错误检测从48.0%降至24.9%，但歧义类失败占51.2%，最终实例级验证是制约性能的关键环节。

## 7. 优点

- **创新性**：明确提出"对话到状态"（dialogue-to-state）原则，将对话从瞬态上下文转为持久结构化状态，视角新颖且具有方法论价值。
- **结构化记忆设计**：价值图、房间图、拓扑图、对象图四类记忆与三种问题类型（信息/路线/消歧）有机耦合，每种回答都对应明确的记忆更新路径，架构清晰可解释。
- **零样本能力**：无需任务策略训练即可超越学习型对话基线，展现出强大的泛化潜力，降低了训练成本和对大规模标注数据的依赖。
- **不确定性建模**：熵感知VQA过滤（从logits提取不确定性而非仅用离散答案）和相似度阈值分层（REJECTED/PENDING/CONFIRMED）是对检测可靠性的精细处理。
- **路线接地机制**：将路线回答通过图搜索+分支均衡+LLM匹配接地到拓扑路径，并分离短期路线掩码和长期历史掩码，多时间尺度引导探索。
- **实验较全面**：从模拟到真实世界、从整体到模块、从成功到失败的多角度验证。

## 8. 不足与局限

- **算力细节缺失**：未报告模型推理时间、实际计算开销或GPU资源，不利于复现和效率评估。
- **真实世界验证有限**：仅展示一个代表性案例，缺乏统计意义上的真实世界实验数据（成功率、多次重复、不同场景变体）。

- **评估环境有限**：只在VL-LN单一基准上评测，未在CVDN、DialFRED等其他对话导航基准上验证泛化性。
