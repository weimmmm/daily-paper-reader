## 摘要
长视界人形机器人视觉-语言-动作（VLA）控制，使用头戴式立体相机，需要能够利用互补视图同时保持与预训练表示兼容的视觉接口。现有接口常常丢弃互补的立体证据，或者在不保留原生主视图通路的情况下融合额外观测，并将辅助信息适应机器人具身。我们提出EATR-Stereo，一种具身感知令牌路由框架，它保留主视图令牌，并通过查询同步辅助视图令牌序列来构建主对齐的跨视图辅助令牌（CVAT）。一个身体分割的本体感觉编码器进一步根据机器人配置历史调节令牌级辅助使用，从而在动作生成过程中选择性地纳入立体证据。路由的辅助流增强了预训练VLA的语言和主视觉上下文，同时保持其视觉-语言模型冻结。在具有37维本体感觉状态的33自由度物理人形机器人上，我们在超过100秒的搜索-接近-抓取-放置-返回任务中评估了九种配置。EATR-Stereo实现了60.0%的完整任务成功率，100.0%的抓取成功率和80.0%的阶段成功率。在严重不对称遮挡下，它将恢复率提高到80%，而单独使用CVAT为30%。消融研究进一步表明保留主视图令牌和将跨视图辅助特征与结构化本体感觉路由相结合的重要性。这些结果表明，选择性路由的配对立体证据改善了空间基础，以实现可靠的长视界人形VLA控制。

## Abstract
Long-horizon humanoid vision--language--action (VLA) control with head-mounted stereo cameras requires visual interfaces that can exploit complementary views while maintaining compatibility with pretrained representations. Existing interfaces often discard complementary stereo evidence or fuse additional observations without preserving the native primary-view pathway and adapting auxiliary information to robot embodiment. We present EATR-Stereo, an embodiment-aware token-routing framework that retains primary-view tokens and constructs primary-aligned Cross-View Auxiliary Tokens (CVATs) by querying the synchronized auxiliary-view token sequence. A body-segmented proprioceptive encoder further conditions token-wise auxiliary usage on robot configuration history, enabling selective incorporation of stereo evidence during action generation. The routed auxiliary stream augments the language and primary-visual context of a pretrained VLA while keeping its vision--language model frozen. On a 33-DoF physical humanoid with a 37-D proprioceptive state, we evaluate nine configurations in over-100-s search--approach--grasp--place--return tasks. EATR-Stereo achieves 60.0% full-task success, 100.0% grasp success, and 80.0% stage success. Under severe asymmetric occlusion, it improves recovery to 80% compared with 30% for CVAT alone. Ablation studies further show the importance of preserving primary tokens and combining cross-view auxiliary features with structured proprioceptive routing. These results demonstrate that selectively routed paired stereo evidence improves spatial grounding for reliable long-horizon humanoid VLA control.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言-动作（VLA）模型将大规模视觉-语言预训练表示迁移到语言条件控制中，近年来已扩展到人形机器人的连续动作生成与全身行为控制。然而，人形机器人与传统机械臂部署场景存在本质差异：双足行走使躯干扰动传导至头戴相机，头部和腰部运动改变视角，手臂和手部运动造成与自身构型相关的自遮挡。这些因素导致长时程任务中视觉证据容易丢失，且错误会沿任务阶段传播累积。
- **核心问题**：现有 VLA 视觉接口未能充分挖掘同步立体相机提供的**配对关系**（correspondence、disparity 与互补可见性）：
  - 单目输入缺乏双目视差和遮挡交替视角；
  - 简单 token 拼接保留了两幅图像但没有显式建立跨视图空间推理；
  - StereoPolicy 虽显式关联两视图，但其 VLA 变体用融合后的立体表示替换原始图像 token，破坏了预训练的单目 token 结构；
  - 已有方法没有根据机器人**身体语义状态**（腿、腰、臂、头等）调节配对视图的选用，尽管视角和遮挡都依赖构型。
- **论文主张**：同步立体对的可用信号是"配对关系"本身，而不仅是多一张图。应保留预训练主视图通路，同时以**具身感知（embodiment-aware）**的方式选择性路由辅助视图证据，从而在不改写预训练 VLM 的前提下提升长程人形机器人操作的空间接地能力。

### 2. 方法论：核心思想、关键技术细节

**总体框架**：EATR-Stereo 是一个面向预训练人形 VLA 的具身感知 token 路由框架。整体流程为：同步立体图像对与语言指令由冻结的 Cosmos VLM 联合编码 → 跨视图注意力构建主对齐辅助 token（CVAT）→ 身体分段的 proprioceptive 编码器调节 token 级路由权重 → 路由后的辅助 token 与主视图 token、语言 token 拼接 → 送入共享的 flow-matching 动作专家生成动作块。

**关键技术组件**：

1. **主视图保留与 CVAT 构建**
   - 将立体对中一视图固定为主视图 \(I^p\)，另一为辅助视图 \(I^a\)。
   - 冻结 VLM 对图像对与语言指令联合编码，按 token 来源分离为语言序列 \(L_t\)、主视觉序列 \(M_t\) 和辅助视觉序列 \(A_t\)。
   - 对 \(M_t\) 和 \(A_t\) 添加学习的视图角色嵌入。
   - **主序列 \(M_t\) 沿原生视觉通路保持不变**；辅助序列 \(A_t\) 用于构建 CVAT 流。
   - 采用多头跨视图注意力：以主序列为查询（Q），辅助序列为键和值（K、V），使得每个主 token 从完整同步辅助序列中自适应聚合证据。输出经拼接投影与 token 级前馈残差块后得到 \(C_t\)。
   - 由于跨注意力对每个主查询产生一个输出，\(C_t\) 继承了 \(M_t\) 的 token 索引，建立了主对齐的 token 级对应。

2. **具身感知路由（Embodiment-Aware Routing）**
   - 将 37 维 proprioceptive 状态划分为 5 个身体语义组：legs、arms、head、waist、robot pose。
   - 每组 \(K\) 帧历史经 Flatten → LayerNorm → 独立 MLP → 加组类型嵌入，得到段表示 \(z_{t,g}\)。
   - 通过注意力加权池化与均值池化融合得到共享的 proprioceptive 条件 \(h^s_t\)。
   - 对每个 token 索引 \(i\)，路由描述子由主 token、CVAT token、二者元素级绝对差与元素级乘积、以及身体条件拼接构成，经轻量 MLP 和 sigmoid 输出标量门控 \(r_{t,i} \in (0,1)\)，对 CVAT token 逐元素缩放。
   - **路由器只缩放 CVAT 流，主 token 不变**；主 token 仅参与路由描述子计算。

3. **VLA 集成与训练**
   - 路由后的辅助 token 与语言 token、主 token 拼接为上下文 \(E^{VLA}_t = [L_t; M_t; \tilde{C}_t]\)，送入 GR00T N1.7 动作专家。
   - 分段 state 表示仅用于辅助 token 路由，不替换原有状态通路。
   - 采用 flow-matching 目标 \(\mathcal{L}_{FM}\) 训练。冻结 Cosmos VLM，联合优化 CVAT 模块、分段状态编码器、token 路由器与动作专家。
   - 部署时：动作块异步预测并放入执行缓冲，采用**局部三次 B 样条拼接**确保动作块切换处的位置与速度连续；外部 VLM 提供子任务完成信号，由有限状态机（FSM）决定保留或切换当前指令。

### 6. 主要结论与发现

- **主对比**：EATR-Stereo 在物理人形上达到 60.0% 全任务成功率、100.0% 抓取成功率、80.0% 阶段成功率，全面优于 StereoPolicy（45/85/65%）和 GR00T 系列基线（20–35/45–80/32.5–57.5%）；ID/OOD 阶段成功率分别为 90.0%/70.0%，OOD 优势显著。
- **仿真验证**：EATR-Stereo 在 RoboCasa365 以 43.33% 成功率领先所有对比方法（第二名为 CVAT，39.44%）。
- **消融结论**：
  - 保留主 token（CVAT 双流）比直接修改主 token（Main-XAttn）全任务成功率提高 30.0 pp；
  - 平坦状态编码（CVAT-Flat）相对无路由（CVAT）提升抓取与阶段成功率；
  - 身体分段状态路由（EATR-Stereo）进一步将全任务/抓取/阶段成功率提升至 60/100/80%。
- **遮挡恢复**：EATR-Stereo 在严重不对称遮挡下恢复成功率 80%，显著超过 CVAT-Flat（60%）和 CVAT（30%）；平均恢复时间 22.4 s，较 CVAT-Flat 降低 46.3%。
- **泛化与语义**：EATR-Stereo 在 ID/OOD 位置均保持 100% 抓取成功率（零 ID–OOD 差距），同时保持 100% 左右指令和 80% 颜色指令遵从。
- **训练效率**：EATR-Stereo 以仅比 GR00T 多 5.8% 的训练时间换取 22.5 pp 的阶段成功率提升；相比 Estimated-Depth VLA（同样 80% 阶段成功率），训练成本降低约 3.8 倍。
- **行动连续性与计算开销**：动作块生成采用异步计算 + 局部 B 样条拼接，在 10 Hz 控制频率下，块切换时计算量较小，实测 10.95 小时训练显著低于估计深度 VLA 的 41.8 小时，保证了部署可行性。

### 7. 优点

- **保留预训练表示完整性**：主视图 token 沿原生通路不变，仅添加辅助流，避免破坏冻结 VLM 的表示结构，兼容性好。
- **显式利用配对立体关系**：通过跨视图注意力构建主对齐 CVAT，比简单拼接更有效地利用同步性和基线几何关系。
- **具身感知路由机制新颖**：按身体语义段（腿/腰/臂/头/位姿）编码 proprioceptive 历史，以 token 级门控方式选择辅助证据，使视觉融合适应机器人构型变化，而非静态融合。
- **轻量高效**：冻结 VLM，仅增加少量可训练模块（CVAT、路由、状态编码器），训练开销几乎与 GR00T 基线持平。
- **实验设计较系统**：仿真与真实机器人结合，覆盖位置泛化、语义遵从、遮挡鲁棒性、训练成本和动作连续性多个维度。
- **行动执行工程处理务实**：B 样条拼接有效解决动作块切换的不连续问题，异步缓冲和外部 VLM 子任务监控提供了完整的部署流水线。

### 8. 不足与局限

- **物理实验规模有限**：每种方法仅 20 次物理试验，遮挡测试仅 10 次，统计显著性未报告，结果可能受随机波动影响。
- **任务和平台覆盖窄**：仅在单一 33-DoF 人形平台（HONOR Omega 1.0）和单类长程任务上评估，未涉及多平台、多任务类型（如双上肢协调操作、动态交互）的泛化验证。
- **未建模深度与不确定性**：作者自认未引入显式深度表示和校准的不确定性建模；依赖冻结 VLM 的隐式空间推理，对极端光照或纹理缺失场景的鲁棒性未验证。
- **语言指令覆盖有限**：语义合规仅测试了左右（100%）和颜色（80%）两类指令，未覆盖更复杂的空间关系或组合指令。
- **基线适配的公平性**：StereoPolicy 和 GR00T-Wide 等基线是适配到同一骨干，但适配方式和超参可能非最优；QwenPI0.5 仅在仿真中评估，未在物理人形上对比。
- **遮挡恢复率置信度不足**：30% vs 80% 的差异基于每方法 10 次试验，未报告置信区间或显著性检验；EATR-Stereo 在严重遮挡下仍有 20% 失败率。
- **训练与部署计算细节不完整**：未报告单次物理实验的推理时延、显存占用、动作块生成异步缓冲的延迟等工程细节；训练成本对比中 Estimated-Depth VLA 的微调层数和流程描述较简略。
- **受限的观测设定**：仿真中排除腕部相机，物理实验中未使用腕部视觉，限制了与实际常见部署配置的直接可比性。
