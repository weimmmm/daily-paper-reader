## 摘要
使用头戴式立体相机进行长时程人形视觉-语言-动作（VLA）控制，需要能够利用互补视图同时保持与预训练表示兼容的视觉接口。现有接口常常丢弃互补的立体证据，或在未保留原生主视图路径、未根据机器人具身调整辅助信息的情况下融合额外观测。我们提出EATR-Stereo，一种具身感知的令牌路由框架，保留主视图令牌，并通过查询同步的辅助视图令牌序列构建主视图对齐的跨视图辅助令牌（CVAT）。一个身体分割的本体感觉编码器进一步根据机器人配置历史对令牌级辅助使用进行条件化，从而在动作生成过程中选择性整合立体证据。路由的辅助流增强预训练VLA的语言和主视觉上下文，同时保持其视觉-语言模型冻结。在具有37维本体感觉状态的33自由度物理人形机器人上，我们在超过100次搜索-接近-抓取-放置-返回任务中评估了九种配置。EATR-Stereo实现60.0%的全任务成功率、100.0%的抓取成功率和80.0%的阶段成功率。在严重不对称遮挡下，它将恢复率提高到80%，而仅使用CVAT时为30%。消融研究进一步表明保留主令牌以及将跨视图辅助特征与结构化本体感觉路由相结合的重要性。这些结果表明，选择性路由的配对立体证据改善了空间接地，从而支持可靠的长时程人形VLA控制。

## Abstract
Long-horizon humanoid vision--language--action (VLA) control with head-mounted stereo cameras requires visual interfaces that can exploit complementary views while maintaining compatibility with pretrained representations. Existing interfaces often discard complementary stereo evidence or fuse additional observations without preserving the native primary-view pathway and adapting auxiliary information to robot embodiment. We present EATR-Stereo, an embodiment-aware token-routing framework that retains primary-view tokens and constructs primary-aligned Cross-View Auxiliary Tokens (CVATs) by querying the synchronized auxiliary-view token sequence. A body-segmented proprioceptive encoder further conditions token-wise auxiliary usage on robot configuration history, enabling selective incorporation of stereo evidence during action generation. The routed auxiliary stream augments the language and primary-visual context of a pretrained VLA while keeping its vision--language model frozen. On a 33-DoF physical humanoid with a 37-D proprioceptive state, we evaluate nine configurations in over-100-s search--approach--grasp--place--return tasks. EATR-Stereo achieves 60.0% full-task success, 100.0% grasp success, and 80.0% stage success. Under severe asymmetric occlusion, it improves recovery to 80% compared with 30% for CVAT alone. Ablation studies further show the importance of preserving primary tokens and combining cross-view auxiliary features with structured proprioceptive routing. These results demonstrate that selectively routed paired stereo evidence improves spatial grounding for reliable long-horizon humanoid VLA control.

- 论文关注**长时程人形机器人视觉-语言-动作（VLA）控制**任务。在人形机器人头部安装双目立体相机时，视觉接口需要同时利用左右视图的互补信息，同时保持与预训练 VLA 模型的兼容性。
- 现有 VLA 视觉接口存在三类主要缺陷：
  - **单目输入**：丢弃了双目视差与另一视角对遮挡区域的补充可见性；
  - **简单拼接双图**：虽保留两幅图像，但未显式建模跨视图一致的几何与空间关系；
  - **替换式融合**（如 StereoPolicy 的 VLA 变体）：将原生主视图 token 替换为融合后的表示，破坏了预训练的单目 token 结构。
- 此外，人形机器人全身运动（步态、躯干扰动、头/腰运动、手臂自遮挡）使视觉观测具有**具身依赖性**，而现有视觉-本体感觉融合方法并未根据身体语义状态对视图选择进行条件化。
- 因此，论文提出 **EATR-Stereo**：一种在保留主视图原生 token 通路的同时，通过辅助视图查询构建“主视图对齐的跨视图辅助 token（CVAT）”，并利用身体分段的本体感觉历史进行 token 级路由，实现选择性融合立体证据的框架，且不修改预训练视觉-语言模型。

## 2. 论文提出的方法论

**核心思想**：将同步立体对中的一帧作为主视图，另一帧作为辅助视图；保留主视图 token 的原生通路，额外构造一条主视图对齐的辅助流，并通过具身状态感知的路由器决定每个 token 的融合权重。

**关键技术细节**：

- **跨视图辅助 token 构造（CVAT）**：
  - 同步立体对与语言指令由冻结的 Cosmos VLM 联合编码，得到语言序列 \(L_t\)、主视图 token 序列 \(M_t\) 和辅助视图 token 序列 \(A_t\)。
  - 主视图 token \(M_t\) 保持不变，辅助序列 \(A_t\) 通过多头交叉注意力生成 CVAT：
    \[
    Q_h = \mathrm{LN}(M_t)W_Q^h,\quad K_h = \mathrm{LN}(A_t)W_K^h,\quad V_h = \mathrm{LN}(A_t)W_V^h
    \]
    \[
    O_h = \mathrm{softmax}\left(\frac{Q_h K_h^\top}{\sqrt{d_h}}\right)V_h
    \]
  - 多头输出拼接后经投影与残差前馈得到 \(C_t\)。由于每个主 token 作为 query，\(C_t\) 继承了 \(M_t\) 的 token 索引，实现主视图对齐。

- **具身感知路由**：
  - 将 37 维本体感觉状态分为 5 个身体语义段：腿、手臂、头、腰、位姿。
  - 每个段的 K 帧历史经 LayerNorm、独立 MLP 和段类型嵌入映射为段表示 \(z_{t,g}\)。
  - 通过注意力加权池化与均值池化融合得到共享本体感觉条件 \(h_s_t\)。
  - 对每个 token，路由器使用主 token、CVAT token、二者差/逐元素积以及 \(h_s_t\) 拼接，经轻量 MLP 输出标量门控 \(r_{t,i}\)，缩放 CVAT token：
    \[
    \tilde{C}_{t,i} = r_{t,i} C_{t,i}
    \]
  - 主 token \(M_t\) 不自适应缩放，仅作为路由描述子的输入。

- **VLA 集成与训练**：
  - 路由后的辅助 token 与语言、主视图 token 拼接后输入 GR00T N1.7 动作专家，使用流匹配目标训练：
    \[
    \mathcal{L}_{\text{FM}} = \mathbb{E}_{t,\tau}\left\| v_\theta(Y_t^\tau, \tau | E_t^{\text{VLA}}, S_t) - u_\tau \right\|^2
    \]
  - Cosmos VLM 保持冻结，仅训练 CVAT 模块、分段状态编码器、路由器与动作专家。

- **部署细节**：异步动作块缓存、局部三次 B 样条拼接（保证动作连续性）、外部 VLM 进行子任务完成判别和指令切换。

## 6. 论文的主要结论与发现

- EATR-Stereo 在物理人形长时程任务上取得 **60.0% 全任务成功率**、**100.0% 抓取成功率**、**80.0% 阶段成功率**，全面超过所有基线。
- 相比 StereoPolicy，EATR-Stereo 全任务成功率提高 15.0 个百分点；相比 GR00T 双图基线提高 25.0 个百分点。
- OOD 位置抓取成功率为 100%，ID 与 OOD 无差距，表明立体辅助+具身路由改善了空间泛化。
- 在严重不对称遮挡下，EATR-Stereo 的恢复成功率为 80%，而仅用 CVAT（无状态路由）为 30%，且恢复时间显著缩短（22.4 秒 vs 55 秒以上）。
- 消融证明：
  - 保留主视图原生 token 比修改主视图（Main-XAttn）更有效（55% vs 25%）；
  - 身体分段的本体感觉路由优于平铺状态（60% vs 55% 全任务，100% vs 90% 抓取）；
  - 使用 CVAT 优于直接采用 StereoPolicy 式融合（55% vs 40%）。
- 效率方面：EATR-Stereo 仅比 GR00T 增加 5.8% 训练时间，即达到与微调 4 层 VLM 的 Estimated-Depth 方法相同的阶段成功率，但训练成本仅为后者的约 1/4。

## 7. 优点

- **方法设计巧妙**：在不修改预训练 VLM 的前提下，以轻量级附加模块实现立体信息的自适应融合，具有即插即用性。
- **保留原生主视图通路**：避免破坏预训练表示，与现有 VLA 生态兼容性好。
- **具身感知路由**：利用身体语义分段的本体感觉状态控制辅助 token 的融合权重，使视觉证据利用方式随身体姿态和自遮挡情况动态变化，具有较强的可解释性。
- **实验覆盖全面**：物理人形+仿真机械臂双验证；包含多种基线、多种消融、OOD 泛化、遮挡恢复、训练成本对比，实验设计系统化。
- **部署细节务实**：异步缓冲与 B 样条动作拼接保证实时控制连续性，外部 VLM 完成高层任务编排，体现工程可行性。

## 8. 不足与局限

- **物理实验规模有限**：每配置仅 20 次试验，长时程任务中随机因素多，结果可能受偶然性影响；缺乏多次随机种子和置信区间报告。
