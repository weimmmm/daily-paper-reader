## 摘要
请求到交接的间隙有三个耦合来源：请求时预期行为的模糊性、动作生成期间累积的物理状态漂移，以及新动作最终接管控制时的残余不兼容性。BICPO-VLA依次解决这些问题。首先，一个指令感知的因果历史编码器识别由命令和当前任务进度支持的行为。其次，顺序Haar子空间生成将每个动作块分解为互补的成对支架系数和残差系数，从而能够进行两个专门的生成阶段和精确重建。通过减少在原始动作空间中的迭代细化，缩短了机器人在新块可用之前继续移动的时间间隔。最后，BICPO将已知的传出动作滚动到实际的交接状态，并在行为匹配的候选者之间应用参考相对的Flow-DPO，使生成的动作块适应剩余的请求到交接不匹配，而不改变其预期行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

## 1. 论文的核心问题与整体含义

**研究动机与背景**

- 异步动作分块（asynchronous action chunking）是 VLA（Vision-Language-Action）模型部署中的常见模式：机器人执行上一段动作块（outgoing chunk）的同时，模型并行推理下一段动作块（next chunk）。
- 由于推理需要时间，新动作块在“请求时刻”的语境中生成，却要在“交接时刻”才真正接管控制。这段间隙（request-to-handoff gap）有三个耦合的来源：
  1. **行为意图模糊**：请求时刻对“应该执行什么行为”存在歧义；
  2. **物理状态漂移**：动作生成期间机器人继续运动，状态发生偏差；
  3. **残余不兼容**：新动作块与实际交接状态之间存在边界跳变或运动趋势断裂。
- 一个语义正确（符合指令与任务进度）的动作预测，仍可能因交接不兼容而引发“边界跳变”或“运动趋势断裂”，导致任务失败。
- 论文的核心洞察是：**一个行为（behavior）定义了一个动作实现族（action fiber），而非唯一轨迹**。同一行为族内的成员共享任务语义，但在局部运动细节和交接兼容性上存在差异。因此，异步控制应被重构为“在行为语义有效的动作族内，选择交接兼容的实现”，而非单纯追求全局平滑。

## 6. 论文的主要结论与发现

1. **行为识别与交接适配的分离是有效的**：指令感知的视觉路由/历史编码、Haar 结构化实现、交接条件选择三者的分解显著优于将它们耦合的做法。
2. **结构性收益**：Haar 正交变换提供精确重建，不引入重构瓶颈，支架-残差的顺序生成缩短了交接间隔。
3. **偏好优化优于直接回归**：参考相对 Flow-DPO 能同时降低交接跳变和趋势失配，几乎不损失成功率；直接 SFT（模仿优选候选）则显著损害成功率（如 π0.5-FM 从 96.9% 降至 49.1%）。
4. **可移植性**：仅 DPO 目标即可移植到 π0.5、Legato、RTC，降低跳变成本（15.8%–40.3%）与趋势失配（11.5%–21.2%），而成功率变化仅 0.1–0.2 点。
5. **鲁棒性**：在延迟 k=3–5 或随机延迟下，交接成本几乎不变，说明滚动交接条件具有良好的泛化能力。
6. **总体效果**：CALVIN 上达到 4.52 Avg. Len 和 80.7% 五子任务完成（优于 B-VLA 的 4.36 和 77.3%）；RoboTwin 上 65.8% 总体成功率（优于 B-VLA 60.4%）；真实世界 69.3%（优于 B-VLA 60.2%）。

## 7. 优点

- **问题表述清晰且有洞察力**：“行为条件动作纤维”的概念将交接问题形式化为“同纤维内的交接条件选择”，比直接施加全局平滑损失更合理。
