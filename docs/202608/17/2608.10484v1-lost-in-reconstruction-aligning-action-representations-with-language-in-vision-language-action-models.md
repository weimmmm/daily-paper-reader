## 摘要
动作动词不仅描述动作的物理结果，还描述这些动作是如何执行的。然而，在视觉-语言-动作模型（VLA）中，动作表示通常是在原始动作空间中通过L1/L2损失进行重建优化的，其中数值上的接近并不一定反映语言上有意义的区别。在BridgeV2上，我们表明动作轨迹包含超出视觉状态变化的动词接地信息，而仅重建的离散标记化会系统地侵蚀这些信息。为了解决这个问题，我们引入了SALT，一个语义对齐的动作分词器，它通过一个辅助目标增强了VQ-VAE风格的分词器，该目标要求一个冻结的视觉-语言模型从量化的动作潜变量中恢复出情节指令。使用SALT训练的策略在SimplerEnv中实现了71.9%的平均成功率，而仅重建的VQ-VAE分词器为42.7%，FAST为31.2%。SALT还开发了动词专用代码，同时保持了重建保真度。这些结果表明，机器人动作轨迹提供了语言接地的一个来源，并且在动作表示中保留这种结构可以显著改善语言条件下的控制。

## Abstract
Action verbs describe not only the physical outcomes of actions, but also how those actions are performed. Yet action representations in vision-language-action models (VLAs) are typically optimized for reconstruction under L1/L2 losses in raw action space, where numerical proximity need not reflect linguistically meaningful distinctions. On BridgeV2, we show that action trajectories contain verb-grounding information beyond visual state changes, and that reconstruction-only discrete tokenization systematically erodes this information. To address this problem, we introduce SALT, a Semantically ALigned action Tokenizer that augments a VQ-VAE-style tokenizer with an auxiliary objective requiring a frozen vision-language model to recover the episode instruction from quantized action latents. Policies trained with SALT achieve 71.9% average success in SimplerEnv, compared with 42.7% for a reconstruction-only VQ-VAE tokenizer and 31.2% for FAST. SALT also develops verb-specialized codes while maintaining reconstruction fidelity. These results show that robot action trajectories provide a source of language grounding and that preserving this structure in action representations can substantially improve language-conditioned control.

### 1. 论文的核心问题与整体含义

- **研究动机**：视觉-语言-动作模型（VLA）是当前机器人操控领域的重要范式。它将预训练的视觉-语言模型（VLM）扩展用于机器人控制，通过视觉观测和自然语言指令来预测动作。然而，现有的VLA在构建动作表示时，通常采用原始动作空间中的L1/L2重建损失进行优化，这一过程中**数值上的接近程度并不等同于语言意义上的语义区别**。这种设计与语言抽象之间的错位，形成了VLA在动作接口处的"瓶颈"。
- **核心问题**：动作动词不仅描述动作的物理结果（action goal），还描述动作的执行方式（motion dynamics），如运动轨迹、接触模式、夹爪时序等。如果动作表示在离散化/分词化过程中丢失了这些语言接地（language grounding）信息，那么下游语言条件控制策略将无法充分理解语言指令所表达的动作语义。
- **整体含义**：该工作揭示了VLA中一个被忽视的环节——动作表示的语言对齐问题。动作轨迹本身是语言接地的重要来源，保留这种结构能显著改善语言条件控制，这为VLA的设计提供了新的设计原则：**动作表示不仅要保留可执行的轨迹信息，还应保留语言所表达的动作抽象结构**。

### 2. 论文提出的方法论（SALT：语义对齐的动作分词器）

- **核心思想**：在VQ-VAE风格的动作分词器训练中，引入一个**辅助生成式对齐目标**——量化后的动作潜变量需要能够通过一个冻结的视觉-语言模型（pLM）恢复出对应episode的自然语言指令。这种语言监督压力使得动作空间的分割方式向语言上有意义的方向对齐，而不改变下游VLA的架构和训练流程。
- **关键技术细节**：
  - **分词器架构**：采用残差VQ-VAE（Residual VQ-VAE），每个8步动作块（chunk）被编码为7个残差组的codebook索引（每组256个code），量化潜变量为各codebook向量之和。
  - **对齐损失设计**：一个episode被分为M个动作块，每个块的量化潜变量q_i经过可学习的标量增益g和位置编码PE(i)后，转换为软前缀嵌入（soft prefix embedding）p_i，送入冻结的pLM，以自回归方式生成episode指令。Lalign = -1/L Σ log pLM(w_t | w<t, P, s)。
  - **总训练目标**：L = L_recon + L_VQ + λ·L_align，其中L_recon为动作重建损失，L_VQ为codebook和commitment损失。梯度通过直通估计器（straight-through estimator）传播回编码器和codebook。
  - **冻结VLM策略**：对齐用的pLM在训练中保持冻结，训练完成后被丢弃；分词器冻结后，下游VLA正常预测离散token ID，再用分词器解码为连续动作。
  - **无需显式动词列表**：该目标直接基于自由形式的自然语言指令，不需要预定义动词清单，也不需要额外的文本编码器或对比学习负样本对。

### 3. 实验设计

- **数据集**：
  - **BridgeV2**：真实机器人遥操作操控数据集，WidowX 250 6-DoF机械臂+平行夹爪，桌面操作任务，每个episode约37个时间步。指令为自由形式的自然语言，经SpaCy依赖解析提取并词形还原后，保留17个动词类别，覆盖27,271个episodes；90/10划分训练/验证集（24,544/2,727）。
  - **SimplerEnv**：视觉匹配的WidowX仿真评估套件，包含4个桌面任务（spoon on towel、carrot on plate、stack green block on yellow、eggplant in basket），每个任务24个episodes，共96次rollout，开放循环执行8步动作块。
- **诊断实验1（动词信息分解）**：将动词信息分解为"动作目标"（首尾帧视觉变化，用DINOv2-S表征）和"运动动力学"（7-DoF动作轨迹），用Transformer探针在5折交叉验证下估计I(Y;X)互信息。结果表明运动动力学提供了视觉目标之外独有的动词接地信息（如move、put、push等动词）。
- **诊断实验2（离散分词化语义损失）**：在Bin、FAST、VQ-VAE三种分词器族上，以不同压缩级别（位率）测量动词与分词token之间的互信息，发现所有仅重建的分词器都低于连续轨迹参考值，且压缩越强，损失越大。
- **主要对比方法**：
  - **FAST**：频率系数变换+字节对编码，词表1024，每块约7个token。
  - **VQ-VAE**：与SALT相同架构与容量，仅无对齐损失。
  - **SALT**：上述两者基础上加对齐损失。
  - **Native（连续轨迹参考）**：不经过分词化的连续动作探针参考。

### 4. 资源与算力

- **硬件**：NVIDIA L40S GPU（48GB），学术共享集群。
- **策略训练**：每个头条策略（SALT、VQ-VAE、FAST的miniVLA）在2张L40S上训练15k梯度步，全局batch size 128，约1–2天/run。
- **分词器训练**：SALT分词器（14种配置）及消融实验分词器，各在1张L40S上训练4–8小时，总计约150 GPU小时。
- **探针实验**：每组5折Transformer探针约20分钟，全部探针约80 GPU小时。
- **总计算**：包括失败和未报告实验，约1,500 L40S GPU小时。

### 5. 实验数量与充分性评估

- **实验数量**：

  - 3种分词器在SimplerEnv上的端到端部署成功率对比（96次rollout/策略）；

  - 代码-动词共现分析（逐码分布可视化、多数投票查找准确率），覆盖每个残差组和累积组前缀；
  - 消融/对照分析：SALT vs VQ-VAE隔离了对齐损失的影响。
- **充分性评价**：实验设计较为严谨，对照组设置合理（SALT与VQ-VAE完全同架构，仅差对齐损失，排除了压缩率差异带来的混淆），统计手段较扎实（分层5折交叉验证、McNemar显著性检验、配对样本Wilcoxon检验）。但覆盖面仍有限：单数据集（BridgeV2）、单策略架构（miniVLA, 0.5B）、单仿真评估环境（SimplerEnv），未进行真实机器人部署；动词类别仅17类，语言多样性有限。

### 6. 主要结论与发现

- **动作轨迹包含超出视觉结果的动词接地信息**：运动动力学（轨迹）在视觉目标之外贡献约0.059 bits的动词互信息，证明语言接地不仅来自状态变化，还来自动作执行方式。
- **仅重建的分词化系统地侵蚀动词信息**：跨三种分词器族（Bin、FAST、VQ-VAE），token化后的动词互信息均低于连续轨迹参考值，且压缩率越高损失越大。
- **SALT显著提升部署成功率**：SimplerEnv中平均成功率达71.9%，远超VQ-VAE（42.7%）和FAST（31.2%）；在stack和eggplant两个最困难任务上提升最大（分别从33.3%提升至70.8%和79.2%）。
- **语义对齐可超越分词器本身传播**：对齐仅作用于分词器潜变量，但效果传递到了离散token ID和下游VLA习得的动作token嵌入（分别达39.1和43.7宏F1，均优于对比方法），且token ID探针准确率（58.7%）与连续动作参考（58.0%）持平。
- **语义对齐不牺牲重建保真度**：SALT的重建误差（0.088）与VQ-VAE（0.080）接近，运动特征相关性保持≥0.92，即"重新分区"而非"丢失重建质量"。
- **动词专用代码自然涌现**：SALT的词表中出现高选择性代码（如flip代码的P(verb|code)=98%，turn代码74%），且能将有相同语义的不同措辞（如"lever vertical to front"）统一到同一代码中，说明对齐捕捉的是语义而非表面措辞。

### 7. 优点

- **方法简洁且通用性强**：SALT仅干预分词器训练阶段，下游VLA架构和使用方式完全不变，可即插即用（drop-in），设计优雅。
- **无需人工监督标注**：利用现成的自然语言指令作为对齐信号，不需要预定义动词清单、不需要文本编码器或对比学习负样本，降低了工程复杂度。
- **诊断实验设计严谨且有洞察力**：将动词信息分解为目标/动力学两模态，用互信息估计量化分析，从"分词器是否会丢失语义信息"这一关键问题出发，为方法设计提供了扎实的动机依据。R2 commonality分解进一步佐证了结论。
- **多层面验证结果**：从端到端成功率、探针可解码性、重建保真度、代码-动词共现组织等多个维度验证了方法效果，证据链较完整。
- **代码可解释性分析具有启发性**：通过对代码-动词分布的可视化，直观展示了SALT如何重新组织动作词表结构，并发现语义等价聚类的涌现现象，具有很强的分析深度。

### 8. 不足与局限

- **数据语言多样性有限**：BridgeV2过滤后仅17个动词类别，长尾分布严重（move和put占65%），语言多样性不足以充分测试语义tokenization在大词汇量下的推广效果。
- **方法适用范围受限**：SALT仅适用于可学习潜表示的分词器（如VQ-VAE），如何将类似的语义监督扩展到Bin或FAST等固定离散化方案尚未解决。
- **实验规模相对有限**：仅使用0.5B参数的miniVLA，单数据集（BridgeV2），单仿真评估（SimplerEnv），且未进行真实机器人部署验证；大模型、多embodiment预训练、真实世界场景下的增益是否保持未知。
- **缺乏因果机制分析**：论文明确承认，虽然观察到语义对齐带来更可解释的词表和更好的下游表现，但未建立两者之间的因果机制——语义组织的动作代码究竟如何影响策略学习，仍是开放问题。
- **互信息估计的近似性**：I(Y;X)基于探针分类器的交叉熵估计，受探针容量、训练协议和类不平衡影响；17类分布的不平衡（长尾类别样本极少）可能使某些估计不够稳定。
