## 摘要
开放词汇3D场景图为语言引导导航提供了紧凑的语义记忆，但映射对象通常通过单一融合特征或固定的语义标签呈现。这种承诺可能会从任务时接口中移除少数但与任务相关的假设。我们提出OpenBelief-Nav，一种保留证据的对象记忆，它保留观察级短语、可靠性线索和帧掩码来源，同时维护独立的聚合几何和视觉表示。语义相关的短语被整合成与词汇无关的对象信念，任务特定的读取从中执行固定词汇投影或自由形式检索。在五个ScanNet200和八个Replica场景中，全信念投影的mIoU分数分别达到0.2742和0.2912，而匹配的早期承诺读取的分数为0.2393和0.2701。在78次HM3D-YCB导航试验中，共识检索和早期承诺检索均获得60/78次成功，而信念加权检索为58/78，DualMap为55/78。在20次Unitree G1运行中，组织为10个匹配的评估案例，一个允许最多两次验证候选尝试的修正策略，相对于仅执行top-1，将目标确认成功率从6/10提高到8/10。代码将在接收后发布于 https://openbelieve-nav.github.io/。

## Abstract
Open-vocabulary 3D scene graphs provide compact semantic memory for language-guided navigation, but mapped objects are often exposed through a single fused feature or committed semantic label. Such commitment can remove minority yet task-relevant hypotheses from the task-time interface. We present OpenBelief-Nav, an evidence-preserving object memory that retains observation-level phrases, reliability cues, and frame-mask provenance while maintaining separate aggregate geometric and visual representations. Semantically related phrases are consolidated into a vocabulary-independent object belief from which task-specific readouts perform fixed-vocabulary projection or free-form retrieval. On five ScanNet200 and eight Replica scenes, full-belief projection achieves mIoU scores of 0.2742 and 0.2912, compared with 0.2393 and 0.2701 for a matched early-commit readout. Across 78 HM3D-YCB navigation trials, consensus and early-commit retrieval each achieve 60/78 successes, compared with 58/78 for belief-weighted retrieval and 55/78 for DualMap. Across 20 Unitree G1 runs organized as 10 matched evaluation cases, a correction policy permitting at most two verified candidate attempts improves target-confirmation success from 6/10 to 8/10 relative to top-1-only execution. Code will be released upon acceptance at https://openbelief-nav.github.io/.

# OpenBelief-Nav 论文详细总结

## 1. 核心问题与研究动机

### 背景
- 语言引导导航要求机器人能够将自然语言概念（如"带我去灭火器那里"）与持久化的空间知识进行关联。
- 开放词汇3D场景图（Open-vocabulary 3D scene graphs）将度量几何与语言对齐的语义相结合，是当前的主流方案，如 ConceptGraphs、HOV-SG、FSR-VLN、DualMap 等。

### 核心问题
现有系统在**构建场景图时过早进行语义承诺（early semantic commitment）**——即通过单一融合特征、某一选定视角或共识对象状态来暴露物体信息，导致多视角观察中蕴含的、少数但**任务相关的语义假设被提前丢弃**，且无法在任务时恢复。

### 三个严重后果
1. **证据不可恢复**：不同视角可能因遮挡、距离、分割噪声或基础模型的不确定性导致对同一物体的描述不一致；即便正确概念出现在历史观测中，占主导地位的标签仍可能是错误的。
2. **单一语义读取不适用于所有任务**：封闭词表分割需要将语义投影到固定标签集，而导航检索需要对自由形式的查询进行语义落地；两者的最优读取方式不同。实验显示"全信念投影"最适合分割，而"共识检索"和"早期承诺检索"最适合导航。
3. **排名最高的目标在执行中仍只是假设**：语义上看似合理的节点可能是干扰物，或无法从到达观测中得到确认。机器人应验证所选查询-节点绑定，验证失败时应在剩余候选中重新落地原始查询。

## 2. 方法论

### 核心思想：延迟语义承诺（Delayed Semantic Commitment）
OpenBelief-Nav 的核心设计理念是：**对象节点存储的是"证据"而非"决策"**。每个语义决策都在任务时从保存的证据中计算得出，而不是在建图时一次性确定。

### 对象节点表示
每个对象节点的状态定义为：

```
Bi = { Pi, f_vi, Oi, Vi, pi, f_ti, ρi }
```

- **Pi**：点云
- **f_vi**：聚合视觉嵌入
- **Oi**：语言观测列表（保留观测级短语）
- **Vi**：概念证据向量
- **pi**：归一化相对支持分布
- **f_ti**：共识文本特征
- **ρi**：信任状态

**关键分离不变量**：视觉通道与语言通道独立维护，在映射过程中**从不进行破坏性融合**；所有跨模态融合都推迟到任务时读取阶段。

### 技术流程四阶段

**（1）多模态证据获取**
- 视觉-语言模型（VLM）为每帧提出对象短语，提示性分割模型将短语落地为掩码。
- 每个掩码保留：源帧、掩码索引、短语、分割置信度、有效点数、反投影点云、归一化视觉特征。
- 语义证据的保存单元是"观测"，而非最终对象；同一对象的不同观测可保留不同甚至矛盾的短语。

**（2）几何-视觉对象关联**
- 关联采用**保守的几何主导策略**：主要依据点云重叠率，视觉相似度仅用于拒绝不一致的匹配。
- 公式：两个观测关联当且仅当点云重叠 ≥ τg 且视觉特征余弦相似度 ≥ τv。
- 理由是**高精度关联优先**：错误合并会不可逆地混合不同对象的证据，而漏关联只会留下独立候选。

**（3）证据保留的语义信念构建**
- **可靠性权重**：we = ce·√ne（分割置信度 × 3D支撑点数的平方根），因为VLM短语没有可用的逐对象置信度。
- **同义词感知的概念整合**：将语义相似的短语在共享文本空间中聚类为对象级概念假设，减少同义词导致的支持分散。
- **低证据正则化**：使用对称伪计数平滑（Dirichlet风格）：
  ```
  pik = (Vik + α) / (ΣVij + α·Ki), α > 0
  ```
  保持多个竞争假设的非零相对支持。
- **信任状态**：观测数少于阈值时标记为"降级"，自由检索时语言分支权重降低。
- **共识文本特征**：信念加权组合的概念嵌入，仅用于评分，底层信念始终可用。

**（4）任务时读取与执行时验证**

三个语言读取变体：
- **共识检索 H_con**：信念加权共识特征与查询的相似度
- **早期承诺检索 H_early**：仅最高支持概念的嵌入与查询的相似度
- **信念加权检索 H_bel**：所有概念支持度加权的相似度之和

最终对象得分融合视觉和语言分支，权重根据信任状态自动调整（无语言时纯视觉，降级时偏向视觉，可信时偏向语言）。

**固定词表投影**（用于分割基准）：保留所有概念假设，通过视觉证据在保留的语义支持内精炼信念，再投影到基准词表，避免早期标签分配。

### 执行中纠错机制（Algorithm 1）
- 检索到的目标被视为**待验证假设**而非最终事实。
- 到达候选目标后获取局部RGB-D观测，执行三个顺序检查：可见性检查 → 语义相似度检查 → 几何重叠检查。
- 验证失败的候**仅对当前查询排除**，原始查询不变，在剩余映射候选中重新落地。
- 终止条件：候选被确认、无未尝试候选、或达到尝试预算上限。
- 持久图不被修改，不进行全局动态地图修复或缺失目标推断。

## 6. 主要结论与发现

1. **全信念投影在语义分割上最优**：ScanNet200上mIoU 0.2742 vs. 早期承诺0.2393；Replica上0.2912 vs. 0.2701；同时获得最高mAcc和ScanNet200上的最高F-mIoU。这验证了保留次要假设直到词表已知的价值。

2. **不同任务需要不同读取方式**：共识检索和早期承诺检索在导航上并列最高（76.9%），信念加权检索次之（74.4%），但分割任务上全信念投影最优——没有任何单一读取方式在所有任务上普遍最优。

3. **执行时纠错有效**：真实机器人实验中，允许最多两次候选尝试的纠错策略将目标确认成功率从6/10提高到8/10；在混淆候选条件下从1/5提高到3/5；平均访问1.40个候选。

4. **消融验证各组件必要性**：统一证据权重降低分割和导航性能；移除低证据正则化造成最大的导航性能下降；移除同义词整合导致mIoU和导航成功率小幅下降。

5. **与现有方法相比**：导航成功率76.9%超过DualMap（70.5%）、ConceptGraphs（61.5%）和HOV-SG（52.6%）；分割精度也全面超越对比方法。

3. **未处理动态场景**：实验均为静态对象场景；论文明确说明不处理目标移动、新对象引入或全局缺失目标，限制了在真实世界动态环境中的适用性。
