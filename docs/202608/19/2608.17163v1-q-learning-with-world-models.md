## 摘要
离策略强化学习（RL）在样本效率上已显著提升，使得诸如将视觉-语言-动作模型微调为可靠、高性能策略等应用成为可能。世界模型提供了进一步提升样本效率的途径，因为它们预测状态变化而非仅预测动作，但其成功在很大程度上局限于监督策略学习。先前基于模型的强化学习方法通常直接在想象轨迹上优化策略或价值函数，这容易产生复合偏差，并且难以扩展到大规模、高维问题（如真实世界机器人），该问题随任务时域和视觉复杂性而恶化。在本工作中，我们转而探讨能否直接在标准Q学习之上利用世界模型来提升性能，同时保持训练和锚定在真实在线环境中。我们提出QWM框架，该框架利用世界模型在Q学习之上对想象轨迹进行测试时搜索，以在在线轨迹生成和评估期间选择高价值动作。由于策略和价值函数仅基于真实转换进行训练，QWM避免了复合模型偏差，同时仍获得预测搜索的样本效率优势。在具有挑战性的操作基准Robomimic和LIBERO上，QWM在样本效率和性能方面均显著优于强先验的最先进方法。

## Abstract
Off-policy reinforcement learning (RL) has become increasingly sample-efficient, enabling applications such as RL fine-tuning of Vision-Language-Action models into reliable, high-performing policies. World models offer a further lever for sample efficiency, as they predict state changes rather than actions alone, but their success has largely been confined to supervised policy learning. Prior model-based RL methods often optimize the policy or value function directly on imagined rollouts, which is prone to compounding bias and struggles to scale to large, high-dimensional problems such as real-world robotics, a problem that worsens with task horizon and visual complexity. In this work, we instead ask whether we can leverage world models directly on top of standard Q-learning to improve performance, while remaining trained and grounded in the real, online setting. We propose QWM, a framework that leverages world models to perform test-time search over imagined trajectories on top of Q-learning to select high-value actions during both online rollouts and evaluation. Since the policy and value function are trained only on real transitions, QWM avoids compounding model bias while still gaining the sample-efficiency benefits of predictive search. On challenging manipulation benchmarks Robomimic and LIBERO, QWM significantly outperforms strong prior state-of-the-art methods on both sample efficiency and performance.

## 2. 提出的方法论（QWM 框架）

### 2.1 核心思想

- 在标准 Q-learning 之上叠加**测试时搜索（test-time search）**：从当前状态出发，由策略提出候选动作，世界模型想象对应的未来状态，通过树搜索评估每个**候选初始动作**的价值，选择得分最高的动作执行。
- 搜索同时应用于**在线数据采集阶段**（获得更优的训练数据）和**评估阶段**（更有效地执行）。
- 策略与 Q 函数**仅使用真实环境转换进行训练**，世界模型不参与训练数据生成，从而**从根源上避免复合模型偏差**。

### 2.2 树搜索构建（Section 4.1）

- 搜索树由三个量控制：
  - **N**：每个状态节点采样的候选动作数；
  - **K**：每个动作节点查询世界模型得到的下一状态样本数；
  - **D**：搜索深度。
- 结构：状态层与动作层交替，一层状态+一层动作构成一层深度。在深度 d 的状态节点，从策略采样 N 个动作；对每个动作，世界模型预测 K 个未来状态；递归扩展到深度 D。
- 树的深度保持较短，以防止世界模型预测误差积累。

### 2.3 价值聚合（Section 4.2）

- **状态-动作值估计器（V_Q）**：直接用 Q 函数对候选动作打分，低方差、不依赖模型深度，但完全依赖 Q 函数准确性。
- **状态值估计器（V_r）**：利用世界模型预测的奖励和折扣后的下一状态递归值，充分利用想象轨迹，但会随深度累积模型误差。
- **组合节点值**：两者取平均（或加权平均 αV_Q + (1−α)V_r），互补各自失效模式。
- **根节点值（Root value）**：对每个初始候选动作，综合 Q 值、预测奖励与后续树节点值，得到树搜索得分 Q_ts(s₀, a₀ⁿ)，最终选择得分最高的动作。

### 2.4 基于 Q 函数的搜索与剪枝（Section 4.3）

- 为控制树规模，设计**beam-search 式剪枝启发式**：
  - 每条保留路径携带累计折现得分 Σ(b,d)；
  - 在每一深度，按候选子节点的累计得分排序，仅保留前 **J** 条路径；
  - 叶子层采样 N_leaf 个动作并聚合 Q 值。
- 该启发式利用 Q 函数作为搜索策略，高效决定展开哪些节点、剪掉哪些分支。

### 2.5 实际实现（Section 4.4）

- **状态观测（Robomimic）**：使用三层 MLP 实现确定性残差动力学模型 M_ψ(s,a)=s+Δ_ψ(s,a)，在离线演示转换上以 MSE 预训练。稀疏奖励设置下不学习奖励模型。
- **像素观测（LIBERO）**：将 Wan2.2-TI2V-5B 视频生成模型适配为动作条件视频世界模型：引入 MLP 动作编码器，与扩散 Transformer 联合微调（冻结 VAE 与文本编码器），使用 flow-matching 目标。推理时生成 5 帧 128×128 视频片段，取下一帧作为后续观测。

### 2.6 基础算法集成

- QWM 可实现在任意带 Q 函数的离策略算法之上，论文选择了两个 SOTA 算法：
  - **EXPO**（基础策略+轻量编辑策略，OTF 选择 Q 值最高动作）；
  - **RLPD**（离线+在线数据平衡采样、高 UTD 比、集成 Q 函数、层归一化）。

## 3. 实验设计

### 3.1 数据集 / 场景 / Benchmark

- **Robomimic（状态观测）**：四个任务——Lift、Can、Square、Tool Hang（长时程多阶段装配）。Lift 用 10 集演示子集，Can 用多操作者（MH）数据集，Square 和 Tool Hang 用熟练操作者（PH）数据集。
- **LIBERO（像素观测）**：五个代表性任务（Task 60、Task 79、Task 29、Task 28、Task 2），RGB 观测 + 语言指令条件，遵循标准仿真设置。

### 3.2 对比方法

- **Model-free 基线**：EXPO、RLPD、IDQL、QSM、DSRL、QAM、FQL——均为利用在线交互学习 Q 函数的强基线。
- **Model-based 基线**：TD-MPC2（隐式潜在世界模型 + MPPI 规划）、EfficientZero V2（MuZero 式潜在模型 + Gumbel 树搜索），同时报告稀疏与稠密奖励两种变体。

### 3.3 实验协议

- 所有方法共享同一协议：5000 步后开始在线训练、离线数据比例 0.5、UTD=20、batch size 256、TD 折扣 γ=0.99、目标网络更新系数 τ=0.005。EfficientZero V2 使用其官方推荐 UTD=0.4。

## 6. 主要结论与发现

1. **QWM 显著优于 SOTA model-free 与 model-based 方法**：在 Robomimic 全部任务上取得最强性能；TD-MPC2 与 EfficientZero V2 仅能在 Lift 上取得非零成功率，凸显传统 model-based RL 在稀疏奖励操作任务上的局限。
2. **QWM 为任意 Q-learning 基础算法提供一致增益**：在 EXPO 与 RLPD 之上均提升样本效率，且更优的基础算法带来更优的 QWM 效果。
3. **QWM 可扩展到像素观测**：在 LIBERO 上即使仅用采样时搜索，仍一致优于 EXPO，部分任务增益明显。
4. **采样+评估双阶段搜索最有效**：改善经验收集与执行期动作选择具有互补性。
5. **中等搜索深度（D=2）与较小的递归 λ（0.2 左右）效果最优**：平衡未来信息利用与模型误差累积。
6. **搜索需要的展开节点数较少（J 不敏感）**：Q 函数引导的剪枝足以保留高价值分支。
7. **基于 Q 函数搜索显著优于仅基于状态值 V 搜索**：Q 函数提供动作条件信息，是 QWM 优于传统 model-based 搜索（如 MPPI）的关键因素。

## 7. 优点

- **简单而通用**：QWM 是一个即插即用框架，可叠加于任意带 Q 函数的离策略算法之上，不改变底层策略与价值函数的训练方式。
- **从原理上避免复合偏差**：世界模型仅用于测试时搜索，策略与价值函数完全在真实数据上训练，从根源上规避了 model-based RL 的核心缺陷。
- **更强的搜索信号**：Q 函数提供动作条件估计，与状态值互补，优于传统的仅用 V 函数或仅用 reward 的规划/搜索方法。
- **树搜索设计精心**：短视界展开避免误差累积、双价值估计器互补、beam 剪枝控制计算量、Q 函数引导剪枝高效。
- **跨模态验证**：在低维状态与高维像素两种场景均验证了有效性，且在两种基础算法上均获得一致增益。
- **对稀疏奖励友好**：在稀疏奖励操作任务上仍能获得显著收益（无需学习奖励模型）。
- **与 VLA 微调高度相关**：可直接集成到带 Q 函数的 VLA RL 微调管线中，实践价值强。

## 8. 不足与局限

- **计算开销**：树搜索在 rollout 和评估阶段引入显著的计算开销（需多次策略前向 + 世界模型前向），在延迟敏感的真实机器人场景中可能难以承受。
- **世界模型质量依赖**：QWM 整体性能高度依赖世界模型的预测质量，而高质量世界模型的训练本身昂贵且具挑战性。
- **超参敏感性**：搜索深度 D、递归折扣 λ、候选动作数 N 等超参对任务有依赖性，需要调参；λ 的取值与公式中存在常数因子的表述不一致（附录中做了说明），增加复现难度。
- **像素实验不完整**：受算力限制，像素设置下仅用了采样时搜索，未完成全阶段搜索的验证，未能完全展示 QWM 在视觉任务上的全部潜力。
- **实验统计性不足**：未见多随机种子方差和显著性检验报告，削弱了结果可靠性的证据强度。
- **并行扩展性未讨论**：树搜索的逐节点扩展天然适合并行化，但论文未讨论或实现并行加速策略。
- **世界模型在搜索中共享参数**：多分支树搜索时同一世界模型被反复查询，查询误差之间的相关性可能影响搜索质量，论文未涉及。
- **长期任务上的深度限制**：QWM 的短视界搜索（D=2~4）对超长时程任务（如多阶段 Tool Hang）虽有改善，但更深搜索仍受模型误差制约，在极长时程任务上的增益存在天花板。
