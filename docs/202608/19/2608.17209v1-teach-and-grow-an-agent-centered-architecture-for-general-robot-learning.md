## 摘要
端到端的视觉-语言-动作（VLA）模型和世界-动作模型为通用机器人技术提供了一条优雅的路径，但其可靠性受限于经过验证的物理覆盖范围。当不熟悉的物体、传感器、具身或接触超出该覆盖范围，且不存在经过验证的备选方案时，纠正失败需要新的机器人数据、策略更新和回归测试。这种反复出现的负担即为再训练税。与文本不同，具身数据通常必须通过操作机器来生成。我们提出教与成长学习（TGL），一种面向通用机器人学习的智能体中心架构。在其一般形式中，多模态智能体将少量成功的演示转化为可复用的技能块：针对有意义的子目标运行的闭环行为。在新场景中，智能体对这些块进行落地与组合，选择学习到的或几何工具，观察物理结果，并在执行偏离意图时修正路线。技能库存储可执行行为，而结构化经验记忆则承前启后地记录成功、失败与修复。新任务无需针对特定任务的策略再训练即可获得。我们的LIBERO评估达到了最先进的性能；对照研究揭示了技能归纳、持久复用和智能体导向的适应。最后，我们提出教与成长缩放定律假说：若X表示有效的可复用经验，未来任务误差与教学需求应作为X的幂律趋近于不可约下限。因此，该架构将部署视为持续学习的时期，在此期间，一个任务可以使下一个任务变得更容易。

## Abstract
End-to-end vision-language-action (VLA) and world-action models offer an elegant route to general-purpose robotics, but their reliability is bounded by validated physical coverage. When an unfamiliar object, sensor, embodiment, or contact falls outside that coverage and no validated fallback exists, correcting the failure requires new robot data, a policy update, and regression testing. This recurring burden is the retraining tax. Unlike text, embodied data must often be created by operating machines. We present Teach-and-Grow Learning (TGL), an agent-centered architecture for general robot learning. In its general form, a multimodal agent turns a few successful demonstrations into reusable Skill Blocks: closed-loop behaviors for meaningful subgoals. In a new scene, the agent grounds and composes these blocks, selects learned or geometric tools, observes the physical outcome, and revises the route when execution departs from intent. A Skill Library stores executable behavior, while structured Experience Memory carries forward success, failure, and repair. New tasks are acquired without task-specific policy retraining. Our LIBERO evaluation attains state-of-the-art performance; controlled studies expose skill induction, persistent reuse, and agent-directed adaptation. Finally, we propose the Teach-and-Grow scaling-law hypothesis: if X denotes effective reusable experience, future-task error and teaching demand should approach irreducible floors as power laws in X. The architecture therefore treats deployment as a period of continued learning, in which one task can make the next easier.

- 部署不是学习的终点，而是持续学习的时期：**一个任务的成功经验应使下一个任务更容易**（“教学相长”）。

## 二、方法论：核心思想、关键技术细节与公式

### 1. 核心思想

TGL 的设计核心是**将“学习”从参数优化中剥离出来**，改为对显式技能库（Skill Library）和经验记忆（Experience Memory）的结构化更新，而预训练模型权重 θ 在任务获取过程中保持不变。

### 2. 架构组成

| 组件 | 含义 | 作用 |
|------|------|------|
| **Skill Block** | 一个可复用的闭环行为单元，代表一个有意义的子目标（如“抓取目标容器”） | 记录目标、适用条件、策略、接地函数、执行器、验证器与恢复方案 |
| **Skill Library** | 已验证技能块的持久化存储 | 提供可检索、可组合、可版本化的可执行行为 |
| **Experience Memory** | 结构化的文本经验记录 | 保存成功、失败、诊断与修复信息，指导后续决策但不能直接执行 |
| **Agent** | 多模态智能体 | 负责任务级语义决策：选择技能块、判断物理反馈、重新规划路线、要求针对性教学 |
| **Executor** | 机器人原生执行器（控制器、规划器、VLA 等） | 负责高频的度量运动、接触与连续控制 |

### 3. 关键公式与形式化定义

- **学习更新规则**（固定权重下）：

  ```
  θn+1 = θn = θ，
  (Bn+1, Mn+1) = U(Bn, Mn, Dn, ΔHn)，
  Hn+1 = Hn ∪ ΔHn
  ```

  其中 θ 为固定的预训练参数，Bn 为技能库，Mn 为经验记忆，Dn 为少量教学演示，ΔHn 为本次执行的有用经验。

- **Skill Block 表示**：

  ```
  bi := ⟨gi, Si, ρi, γi, Πi, vi, Ri⟩
  ```

  gi 为目标（期望的状态变化），Si 为适用范围，ρi 为可复用策略，γi 为从观测到接地变量的映射，Πi 为兼容执行器集合，vi 为成功/失败判定器，Ri 为有界恢复方案。

- **工作计划**：在每一步语义决策处，Agent 持有有序的剩余计划：

  ```
  τt = ⟨bit,1, bit,2, ... , bit,Lt⟩
  ```

  每一步可依据物理执行结果保持、缩短或重写剩余路线，而非一次性固定的脚本。

- **经验记忆记录**：

  ```
  μj = ⟨task, context, blocks, outcome, diagnosis, repair, evidence⟩
  ```

- **Teach-and-Grow 缩放律假说**：

  ```
  Efuture(X) = E∞ + A·X^(−α)
  Dteach(X) = D∞ + B·X^(−β)
  ```

  其中 X 为**有效可复用经验**（effective reusable experience），Efuture 为未来任务的期望误差，Dteach 为未来任务所需的教学干预时间，E∞、D∞ ≥ 0，A、B、α、β > 0。X 定义为检查点处经验库中所有正权重经验条目的加权和，权重由可靠性、覆盖增益、可检索性、接地有效性与兼容性五个因素预先固定计算。

### 4. 学习流程（算法流程的文字说明）

> **教学 → 跨演示抽象 → 生成技能块 → 动态组合 → 执行与验证 → 反馈与修正 → 持久化成长**

1. **少样本教学**：教师提供少量成功演示（约 2–10 条），Agent 将每条演示按语义状态变化切分为有序分段。
2. **跨演示抽象**：将不同演示中实现同一语义效果的分段对齐，提取共享的角色、关系、顺序与预期效果；实例级细节（位姿、像素、路径、控制参数）留到运行时重新计算。
3. **技能块生成**：基于抽象出的共享策略合成候选 Skill Block，并设定其适用范围；在未参与教学的场景中测试，确认可靠后加入技能库。
4. **动态组合**：在新任务中，Agent 检索相关技能块，按当前场景形成工作计划，但计划可随物理结果随时调整。
5. **执行与验证**：每个技能块在选定的执行器上运行闭环控制，执行结束后由验证器基于新观测判断预期效果是否达成（pass/fail/inconclusive）。
6. **反馈驱动修正**：若效果未达成，Agent 可选择重新观测、更换执行器、重写剩余路线、请求针对性教学或中止。
7. **持久化成长**：成功的技能块进入技能库，失败/修复经验写入经验记忆，成为后续任务的初始化资产；成熟的技能块还可蒸馏到快速策略中执行。

## 七、论文优点与局限性

### 1. 优点

- **问题定义有现实根基**：“再训练税”是对现有端到端范式部署瓶颈的准确概括，切中了机器人学习从实验室到真实场景的痛点。
- **架构设计具有清晰的分工层次**：将语义决策（Agent）、闭环行为（Skill Block）、底层运动控制（Executor）解耦，既保留了大模型的高层推理能力，又避免了其在高频连续控制中的不稳定性。
- **符合认知科学中的技能组合观**：新的复杂行为由已有子技能组合而成，而非从零学习，这与人类动作技能习得的基本原理一致。
- **“固定权重学习”具有工程吸引力**：避免了频繁重训大规模 VLA 模型产生的数据、算力与验证成本，在部署场景中具有实际可操作性。
- **验证思路可复制**：分离状态评估、保存-重载测试、超出范围停止测试等方法论设计清晰，值得借鉴。

### 2. 局限性

- **证据规模远小于主张规模**：论文主张的是一种“通用机器人学习架构”，但核心实验仅基于 LIBERO 仿真中的少量任务与技能块，尚不足以支撑如此宏观的架构性结论。
- **缺乏与主流基线的直接量化对比**：“SOTA”声明缺乏正文中的数字支撑，读者无法判断 TGL 相比 OpenVLA、π0 等端到端模型在相同任务上究竟有多大差距或优势。
- **缩放律假说仍是假说**：两个幂律预测（Efuture(X) 和 Dteach(X)）被明确提出，但没有纵向数据验证，其形式与系数均属推测。
- **真实世界验证缺位**：所有实验均在仿真环境完成，未涉及真实机器人、真实传感器噪声、非结构化光照与接触力学，而这些恰恰是“再训练税”最严重的现实场景。
- **计算代价的透明度不足**：未报告 Agent 在线推理的 token 消耗、每任务平均决策轮次、延迟或总运行时间，使“增量成长成本低于重训”这一核心主张缺乏可量化的成本佐证。
- **可扩展性问题未充分讨论**：当技能库规模从数十增长到数千时，检索效率、组合冲突、版本兼容性和存储管理将面临新的挑战，论文对此着墨有限。
- **复用性验证深度不足**：虽然 8 块库在相关任务上优于 6 块库，但这仅涉及同一任务族的 2 个新增块，尚未证明跨任务域、跨具身的广泛可迁移性。

## 八、关键概念与术语速查

| 术语 | 含义 |
|------|------|
| **再训练税（Retraining Tax）** | 面对新任务/新场景时，端到端模型需要重新训练与验证的累积系统性成本 |
| **Teach-and-Grow Learning（TGL）** | 以智能体为中心，通过技能块与经验记忆的增量更新实现持续学习的架构 |
| **Skill Block** | 可复用的闭环行为单元，包含目标、适用范围、策略、接地函数、执行器、验证器与恢复方案 |
| **Skill Library** | 已验证技能块的持久化集合，支持检索、组合与版本化 |
| **Experience Memory** | 以结构化文本保存成功/失败/诊断/修复经验的语义记忆，辅助但不直接执行 |
| **接地函数（Grounding Function）** | 将原始观测映射为技能所需的语义变量的函数 |
| **验证器（Verifier）** | 基于新观测判断技能目标是否达成的判定器 |
| **恢复方案（Recovery）** | 当技能执行失败时的有界修复策略 |
| **有效可复用经验（Effective Reusable Experience）** | 缩放律中驱动未来学习收益的核心变量，由可靠性、覆盖增益、可检索性、接地有效性与兼容性加权 |
| **工作计划（Work Plan）** | Agent 持有的有序剩余技能序列，可随物理反馈动态重写 |

## 九、与相关研究领域的关系

- **与端到端 VLA 的关系**：TGL 不否定 VLA 的价值，而是将其降级为“执行器”层的一个候选组件；VLA 的策略网络能力仍被复用，但学习不再依赖对其权重更新。
- **与经典机器人技能库（Skill Library/Manipulation Primitives）的关系**：TGL 可视为用大模型作为语义控制器，将传统技能库赋予现代、可扩展的检索与组合接口。
- **与认知机器人学/发展机器人学的关系**：其“积累技能块、组合新行为”的模式与 Piaget 式认知发展及 Berstein 的动作自由度解放观点相呼应，但论文未与这些理论展开深入对话。
- **与终身学习（Continual/Lifelong Learning）的关系**：TGL 在 LIBERO 基准上定位，但其方法不同于常见的 EWC、SI、L2P 等参数正则化或记忆回放方法——它完全绕开参数更新，属于架构层面的终身学习。
- **与大模型 Agent 的关系**：TGL 是“大模型作为机器人高层操纵器”的一个实例，与 Text2Motion、LLM-Planner 等工作共享“LLM 做规划、底层控制器做执行”的总体范式；其创新点在于将中间产物（技能块）制度化、持久化，并允许物理反馈回溯修改计划。

## 十、总体评价与未来方向

### 总体评价

Teach-and-Grow Learning 提出了一种深思熟虑且方向正确的架构性修正：它不再把“学习”狭隘地等同于“权重变化”，而是将其拓展为结构化技能的获取、验证、存储与组合。这一视角的转换能够从根本上回避再训练税，因此思想价值显著。然而，论文的实验证据与架构主张之间存在明显落差——目前提供的仿真结果更多是一套机制可行性的“概念验证”，而非足以证明其规模化优势的“体系化实证”。作为一篇提出新范式的论文，它在学术启发性上是成功的；但要说服社区取代或补充主流端到端路线，还需要在真实机器人、大规模技能库、跨具身迁移以及成本对比上提供更充分的证据。

### 未来研究方向（基于论文自身逻辑自然延伸）

1. **纵向成长实证**：设计大规模、多任务、持续部署的纵向实验，系统记录 Efuture(X) 与 Dteach(X) 随有效可复用经验的演化，真正检验缩放律假说。
2. **跨具身与跨环境的迁移测试**：将同一技能块运用于不同机械臂、不同感知配置与不同物理环境，验证接地函数与适用范围的可泛化性。
3. **技能库规模的工程化研究**：探索高效检索、技能冲突消解、版本演化与自动蒸馏机制，使技能库在千级规模下仍保持可管理性。
4. **成本透明化**：建立“总拥有成本”框架，量化 TGL 的推理成本、教学成本与端到端重训成本在相同能力增长目标下的交叉点。
5. **与基础模型协同**：研究如何让预训练 VLA 或世界模型作为执行器与技能库互相促进——例如用技能库数据生成更高质量的预训练数据，再用更强的基座降低新技能块所需的演示数量。
6. **学习理论层面**：给出“可复用技能”的形式化定义及其组合闭包性质，探讨什么条件下技能块的增量生长能够保证底层任务集合的覆盖收敛。
