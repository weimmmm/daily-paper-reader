## 摘要
尽管大型视觉-语言模型（VLMs）显著推进了具身导航的发展，但其直接部署仍面临挑战，因为现有方法往往迫使VLM进入与其二维预训练先验不一致的非自然动作空间，加之僵化的推理计划和低效的记忆管理。为克服这些限制，我们提出了TAMP-Nav，一个用于高效具身导航的统一框架。首先，我们引入像素到3D动作公式（指向），将导航重新表述为二维视觉提示。具体而言，VLM仅需选择二维像素，然后将其投影到3D坐标以供低级SLAM控制器使用。这种设计自然地将具身执行与VLM固有的二维视觉能力对齐。其次，我们提出了一种集成的选择性推理和锚定轨迹记忆机制（思考与记忆），该机制动态触发思维链，并仅在关键节点保留高保真记忆，将冗余轨迹压缩为轻量级时空指示符，从而保留关键历史信息并增强时空感知。最后，我们通过组相对策略优化（GRPO）设计了一种高效的两级对齐范式（对齐）。通过将全局结果奖励与细粒度过程奖励叠加，这种密集监督将智能体的认知规划与物理环境反馈紧密对齐，赋予模型自适应推理能力。实验表明，TAMP-Nav在R2R-CE上实现了最先进的性能（例如66.2%的SR），并具有较高的运行时和样本效率（仅需9万个训练轨迹）。

## Abstract
Although Large Vision-Language Models (VLMs) have significantly advanced embodied navigation, their direct deployment remains challenging, as existing methods often force VLMs into unnatural action spaces that misalign with their 2D pre-training priors, compounded by rigid reasoning schedules and inefficient memory management. To overcome these limitations, we propose TAMP-Nav, a unified framework for efficient embodied navigation. First, we introduce a Pixel-to-3D Action Formulation (Point) that reformulates navigation into 2D visual prompting. Specifically, the VLM merely selects 2D pixels, which are then projected into 3D coordinates for a low-level SLAM controller. This design naturally aligns embodied execution with the VLM's inherent 2D visual capabilities. Second, we propose an integrated Selective Reasoning and Anchor-Trajectory Memory mechanism (Think and Memorize), which dynamically triggers Chain-of-Thought and retains high-fidelity memory only at critical nodes, compressing redundant trajectories into lightweight Space-Time Indicators, thereby preserving critical historical information and enhancing spatio-temporal perception. Finally, we design an efficient Two-Level Alignment Paradigm (Align) via Group Relative Policy Optimization (GRPO). By superimposing global outcome rewards with fine-grained process rewards, this dense supervision tightly aligns the agent's cognitive planning with physical environmental feedback, endowing the model with adaptive reasoning capabilities. Experiments demonstrate that TAMP-Nav achieves state-of-the-art performance (e.g., 66.2% SR on R2R-CE) with high runtime and sample efficiency (requiring only 90k training trajectories).

## 1. 核心问题与研究动机

- **背景**：大型视觉-语言模型（VLM）在多模态理解方面取得了显著进展，但将其直接部署到具身导航任务中仍面临根本性挑战。现有方法往往迫使VLM输出与其2D预训练先验不一致的动作空间（如低层原子动作、3D坐标回归），导致**几何鸿沟（Geometric Gap）**和空间幻觉问题。
- **三大瓶颈**：
  - **动作形式化的几何鸿沟**：VLM主要在2D图像-文本对上预训练，强行要求其隐式学习复杂的3D几何变换效率低、易产生空间幻觉。
  - **推理调度僵化**：现有方法通常在每一步或固定间隔触发Chain-of-Thought（CoT），虽提升决策质量但引入严重推理延迟，无法在运行效率与导航性能间取得最优平衡。
  - **长时程记忆的关键信息丢失**：全量保留历史视觉特征会导致注意力稀释和内存溢出；而粗暴丢弃又可能丢失关键信息，且缺乏显式时空坐标组织历史信息，难以维持对过往轨迹的清晰理解。

## 2. 方法论：TAMP-Nav 框架

TAMP-Nav 是一个统一框架，围绕四个核心模块构建，对应论文标题中的 "Point, Think, Memorize, Align"：

### 2.1 Point：像素到3D动作形式化（Pixel-to-3D Action Formulation）
- 将VLM的角色简化为“视觉指针”：在每步接收4个360°覆盖的自我中心视图（前/左/后/右），VLM先选择最优视图，再输出指向目标航点的2D像素坐标。
- 通过深度图将2D像素投影为局部3D点：`Pt = Dt,i(u,v) · K⁻¹[u,v,1]ᵀ`，再利用SLAM控制器执行局部运动。
- **优势**：解耦高层视觉提示与低层物理执行，使VLM无需学习复杂几何变换，充分发挥其2D视觉预训练先验。

### 2.2 Think & Memorize：选择性推理与锚点轨迹记忆
- **Anchor-Trajectory Memory（AT-Mem）**：
  - **Explicit Anchors（显式锚点）**：在关键拓扑节点（如十字路口、门口、目标附近）触发CoT时存放三元组 `⟨STI, 高保真视觉特征, 状态描述⟩`，其中状态描述包含任务阶段定位，作为“规划信标”。
  - **Space-Time Indicators（STI，时空指示符）**：非关键路径区间仅保留轻量级时空流，通过2D/1D旋转位置编码（RoPE）+ MLP融合平面坐标 (x,y)、时间索引 t 和偏航角 yaw 的三角函数表示，生成统一STI token嵌入上下文序列。
  - **动态上下文**：将工作记忆（当前步与最近锚点间均匀采样两帧）与长时拓扑记忆序列拼接。
- **Selective Reasoning（选择性推理）**：模型自主决定何时触发深层CoT，仅在关键拓扑节点触发，路径中的常规区段跳过推理，严格约束计算预算。

### 2.3 Align：两级GRPO对齐范式（Two-Level GRPO）
- **冷启动**：先在 MultiNav-CoT 数据集上进行简短的SFT（基座模型为 Qwen2.5-VL-7B），解决RL冷启动问题。
- **本地步骤奖励（Local Step Rewards）** 由5个组件构成：
  - 目标接近奖励（基于测地距离缩减量的Sigmoid映射）
  - 碰撞避免奖励（基于障碍物距离）
  - 停止动作奖励（按距离区间分档）
  - 推理价值奖励（评估CoT是否带来优于基线平均策略的决策）
  - 格式遵守奖励（JSON格式与像素范围合法性）
- **全局轨迹奖励（Global Trajectory Rewards）**：任务成功奖励（含oracle边界松弛）、轨迹效率奖励（SPL）、推理密度奖励（约束CoT比率）。
- **两级策略优化**：每个决策步骤通过温度采样生成 M=4 个候选动作，并利用**退火引导采样（annealed guided sampling）** 以指数衰减的 βk 在早期偏向高局部奖励候选，后期趋近均匀分布。生成 G=8 条完整轨迹后，分别对全局轨迹奖励和局部步骤奖励进行Z-score标准化，叠加得到总优势，采用token级GRPO损失更新策略。

## 7. 优点

- **创新性的动作空间设计**：Pixel-to-3D将VLM的角色简化为“2D指针”，巧妙绕开VLM在3D推理上的固有不擅长，与2D预训练先验对齐，设计简洁且有效。
- **推理/记忆耦合机制新颖**：将“何时思考”（选择性推理）和“记住什么”（锚点轨迹记忆）联合设计，STI轻量级时空token以极小开销保留完整拓扑信息，概念清晰且实用。
- **两级奖励设计细致**：全局结果奖励+局部过程奖励的叠加，辅以退火引导采样，缓解了长时程任务中稀疏奖励的信用分配难题，使模型自主习得“按需推理”的元认知能力。
- **训练效率出色**：仅需90k训练轨迹和约760 GPU小时即达到SOTA，对比方法DualVLN（763k轨迹）和NavFoM（3.37M交互）具有数量级优势。
- **实验系统全面**：从基准评估、长时程分析、消融实验、干扰鲁棒性到真实世界部署，闭环完整；且各消融严格控制变量，结论可信度高。

## 8. 不足与局限

- **对传感器质量依赖较强**：深度准确性和SLAM稳定性直接影响Pixel-to-3D投影和STI编码。虽然受控噪声实验显示一定鲁棒性，但严重深度误差、里程计漂移、定位失败或动态环境将导致较大性能下降。
- **训练依赖特权信号**：GRPO训练需要仿真器提供的进度、成功、SPL、碰撞等特权信息，目前不支持实体机器人在线学习；真实部署仅限仿真策略的零样本迁移。
- **关键节点挖掘启发式的局限性**：使用语义相似度和视觉变化来选取CoT监督，当决策点在视觉上不显著、或指令风格与R2R-CE/RxR-CE差异较大时，可能漏选关键状态，需要额外训练样本或学习式触发标准。
- **STI编码缺乏高度维度**：仅编码平面位置 (x,y) 和偏航角，不含高度，无法显式区分楼层，在多层建筑或不平地形中受限；任务进度描述只能部分补偿。
- **推理密度阈值需重新调整**：奖励函数中CoT比率阈值（0.4/0.6）基于R2R-CE/RxR-CE标定，当任务内在推理需求差异较大时可能需要重新调整。
- **消融中 "Dense CoT" 性能略高于Auto策略**：说明选择性推理在性能上仍有微小代价（-0.6/-0.4 SR），并非无损；其价值主要体现在计算效率而非绝对性能。
