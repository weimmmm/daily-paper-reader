## 摘要
帕累托条件网络通过将单一策略条件化为期望回报命令，学习多种多目标强化学习行为。然而，从命令和状态到动作的局部映射仍然是不透明的。我们为PCN提出命令空间反事实解释：给定固定状态、原始命令和对照动作，我们在黑盒设置下搜索一个最小变化的期望回报命令，使得同一训练策略在该命令下会选择对照动作。我们的贡献有三点。首先，我们将PCN解释形式化为回报命令干预，使用仅回报的PCN变体，以避免时间范围条件带来的额外歧义。其次，我们将对抗机器学习方法应用于强化学习解释。第三，我们引入一种边界种子方向搜索，在命令-动作空间中改进纯局部优化，从而形成我们提出的方法CF-ZOO。所得解释是可操作的，并以用户自身的偏好直观表达：“如果你的权衡略微偏向X，智能体将选择Y。”

## Abstract
Pareto Conditioned Networks learn multiple multi-objective reinforcement learning behaviours by conditioning a single policy on a desired return command. However, the local mapping from command and state to action remains opaque. We propose command-space counterfactual explanations for PCNs: given a fixed state, original command, and foil action, we search, in a black-box setting, for a minimally changed desired-return command under which the same trained policy would choose the foil. Our contributions are threefold. First, we formulate PCN explanations as return-command interventions, using a return-only PCN variant that avoids the added ambiguity of horizon-conditioning. Second, we adapt adversarial machine learning methods to reinforcement-learning explanations. Third, we introduce a boundary-seeded directional search that improves over purely local optimization in the command-action landscape, resulting in our proposed approach CF-ZOO. The resulting explanations are actionable and intuitively expressed in the user's own preferences: "If your trade-off had shifted slightly towards X, the agent would have chosen Y."

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：多目标强化学习（MORL）中，智能体需要在安全、效率、成本等多个目标之间进行权衡。帕累托条件网络（Pareto Conditioned Networks, PCN）是一种紧凑的表示方法，它通过将单一策略条件化为期望回报命令（desired return command）来学习多种 Pareto 最优行为。用户只需修改命令即可在部署时获得不同的行为。
- **核心问题**：尽管 PCN 的命令输入本身是可解释的（用户能看到自己指定的权衡偏好），但从“命令+状态”到“动作”的局部映射仍然是一个神经网络的**黑箱**——用户无法理解为什么在当前命令下智能体选择了某个动作，也不清楚如何修改命令才能让智能体选择另一个动作。
- **研究意义**：多目标强化学习本身天然适合对比性解释（contrastive explanation），因为目标之间的权衡是用户可直接理解的维度。论文抓住 PCN 独特的解释接口——期望回报命令——提出在“命令空间”中搜索反事实解释。这填补了现有 RL 反事实工作（视觉状态反事实、可到达状态反事实、动作序列反事实、策略修改反事实）未覆盖的空白。
- **整体含义**：将对抗机器学习中的优化技术重新用于“解释”而非“攻击”，让用户能以偏好语言获得可操作的解释，例如：“如果你的权衡略微偏向 X，智能体将选择 Y。”这提升了多目标策略的可解释性与用户信任。

### 2. 论文提出的方法论

#### 2.1 核心思想

- 将 PCN 的解释问题形式化为**命令空间中的反事实搜索**：固定状态 st 和训练好的策略，给定原始命令 Rt 和一个对照动作（foil action）af，寻找一个最小的命令扰动 δ，使得在同一策略下 af 成为贪心动作。
- 与视觉反事实或状态反事实不同，论文**干预的是用户可控的期望回报命令**，而非环境状态或输入像素。这使得解释结果天然具有可操作性。

#### 2.2 关键概念与公式

- **命令-动作映射**：πθ(s, R) 表示策略在状态 s、命令 R 下的动作概率分布；贪心动作为 a⋆(s, R) = arg max_a πθ(a|s, R)。
- **仅回报 PCN 变体**：原版 PCN 条件化在 (Rdes_t, hdes_t) 上，即同时包含期望回报与期望时间范围。论文发现 horizon 条件信号不稳定（即使命令对应 Pareto 最优点，仅修改 horizon 也可能产生不稳定或不直观的动作），因此改为仅回报条件化 πθ(a_t|s_t, Rdes_t)，简化了反事实问题（无需同时搜索 δR 和 δh）。
- **目标函数**（类 Carlini-Wagner 结构）：
  - 目标边距（target margin）：Mf(R) = ℓ_af(s_t, R) − max_{a≠af} ℓ_a(s_t, R)，当 Mf(R) ≥ κ 时对照动作获胜。
  - hinge 项：Hf(R) = max{κ − Mf(R), 0}。
  - 最终黑盒优化目标：L(δ) = ‖δ‖²₂ + c·Hf(Π_C(R_t + δ))，其中 Π_C 将命令裁剪到可行区间，c 控制翻转惩罚强度。

#### 2.3 算法流程：CF-ZOO（两阶段）

**阶段一：边界种子定向搜索（Boundary-Seeded Directional Search）**

- 纯局部 C&W/ZOO 式优化在命令-动作空间平坦、非凸或距离目标区域较远时容易失败。因此论文引入方向性边界播种。
- 利用训练时记录的 Pareto 前沿回报集合 F，将其转换为当前时刻的剩余命令：R̃j = Rfront_j − Rcol_t。
- 在这些候选命令上查询 PCN 的 foil 边距，选择边距最大的方向 d = R̃j⋆ − R_t，由此推断每个命令分量的增减方向限制。
- 在推断的方向限制内采样随机单位方向 u（满足 v ~ N(0, I_d), u = v/‖v‖₂），在射线 R(α;u) = R_t + αDu 上搜索，其中 D 为命令尺度归一化对角矩阵。
- 若端点满足 Mf ≥ κ，则用**二分搜索**沿射线回退至最小成功扰动；所有成功的射线候选按缩放距离比较，最近的作为 ZOO 的种子。若无射线成功，则回退到从原始命令开始局部 ZOO。

**阶段二：ZOO 坐标优化（Zeroth-Order Optimization）**

- 采用 ZOO-ADAM 更新规则，在黑盒设置下用中心有限差分估计目标函数的坐标梯度：d∇iL(δ) = [L(δ + he_i) − L(δ − he_i)]/(2h)。
- 每轮随机采样一个坐标，用两次策略查询估计导数，另一次查询评估更新后的命令。在归一化坐标 z = D⁻¹δ 上优化，返回满足缩放距离最小条件的有效命令。

### 6. 论文的主要结论与发现

- **CF-ZOO 显著优于白盒局部优化**：在 797 个对比案例中，CF-ZOO 成功 637 个（79.9%），而 WHITE-CW 仅成功 322 个（40.4%）。除 Fruit-Tree 外，边界种子播种均大幅提升有效性。
- **白盒访问无法替代良好初始化**：在 DST 中 WHITE-CW 仅成功 14/136（10.3%），CF-ZOO 成功 50/136（36.8%），说明纯局部 C&W 式优化即使有梯度也常常无法跨越动作边界——命令-动作景观的非凸性和平坦性限制了梯度方法的有效性。
- **压力测试中方法的总体成功率**：3,195 个案例中成功 2,422 个（75.8%）。在 Collect-Two 和 Fruit-Tree 上达到 100%，在 Minecart（72.6%）和 Reward-Line（70.1%）上也表现良好。
- **成功率低的环境暴露了策略自身的局限**：DST（28.8%）和 Resource-Gathering（34.5%）的部分失败源于 foil 动作难以通过命令改变被诱导——策略可能被状态强烈约束，或目标行为超出了策略的学习支持范围。
- **失败诊断的关键发现**：78.7% 的案例被成功解决；16.6% 为网格不可行 foil（策略可能未学习该行为）；在已知可行的案例中 CF-ZOO 恢复了 94.4%，仅有 5.6% 是真正的搜索失败。
- **解释的稀疏性和直观性**：实际生成的解释通常只改变 1–2 个命令分量（如 Collect-Two 例子中 δR = (0,0,0,−0.1563)），以用户偏好语言呈现。
- **主要方法贡献**：边界种子定向搜索克服了纯局部优化在平坦/非凸命令-动作空间中的易失败性；仅回报 PCN 变体在保持经验性能的同时简化了解释空间。

- **5.6% 的已知可行搜索失败**：即使增加预算至 10 万查询仍无法恢复某些已知可行的反事实，说明算法的鲁

- **5.6% 的已知可行搜索失败**：即使增加预算至 10 万查询仍无法恢复某些已知可行的反事实，说明算法的鲁棒性在极端非凸或不连续的景观上仍有提升空间。

- **命令维度可扩展性未充分验证**：实验环境的命令维度较低（2–4 维），对于更高维目标空间（如 5 个以上回报目标）的搜索效率与解释可读性缺乏系统性验证。

- **反事实唯一性与稳定性未讨论**：由于随机方向采样和坐标优化存在随机性，同一状态可能得到多个不同的反事实命令，论文未分析结果的稳定性、唯一性及对用户理解的影响。

- **多步/时序行为解释缺失**：方法仅生成单步（状态—动作）的反事实解释，未扩展到完整轨迹或长期行为层面，难以回答“什么命令变化能改变整条轨迹的走向”这类问题。

- **计算成本偏高**：CF-ZOO 每查询平均约 48.78 秒，显著慢于白盒基线（8.73 秒），在交互式或实时场景中的实用性受限；论文虽建议 50k 查询预算作为折中，但整体开销仍未充分优化。

- **反事实的可到达性与 Pareto 最优性无保证**：CF 不保证对应回报在实际环境中可达，也不保证反事实命令落在 Pareto 前沿上，这削弱了“若采用该命令，则行为将如此改变”这一解释的因果强度与落地性。

- **缺乏对失败机制的进一步归因**：尽管通过网格诊断区分了“foil 不可行”与“搜索失败”，但没有深入分析“foil 不可行”背后的策略学习缺陷或环境结构限制，也未提出针对这些失败模式的策略改进建议。

### 9. 未来研究方向

基于上述不足，论文与领域内可进一步开展的工作包括：

- **引入人类受试者评估**：面向 MORL/RL 用户与普通使用者，量化解释的可理解性、信任度与决策辅助效果，验证方法在真实应用中的价值。
- **输出 Pareto 最优且可达的反事实命令**：结合可达性分析与前沿投影技术，将反事实约束在可行且最优的命令集合内。
- **加速零阶优化**：利用代理模型（surrogate model）、梯度近似缓存或并行查询来降低推理开销，或探索更高效的贝叶斯优化方案。
- **时序反事实解释**：将单步搜索扩展到轨迹级目标，生成“命令调整→行为轨迹改变”的完整可操作解释。
- **高维命令空间的扩展**：研究维度缩减或因子化搜索策略，使方法适用于 5 个以上回报目标的实际问题。
- **安全与隐私边界讨论**：探索解释机制被恶意利用来操纵决策的风险，并设计相应的防御或检测措施。

### 10. 总体评价

本论文聚焦于多目标强化学习中 PCN 策略的可解释性问题，提出了一种新颖、务实且技术扎实的解决方案——在期望回报命令空间中搜索可操作的反事实解释。方法融合了对抗攻击的成熟优化技术与零阶优化的黑盒友好性，并通过边界种子定向搜索解决了传统局部优化易失效的问题。实验在 8 个环境、3,000 余个案例上对成功率、失败原因、计算开销进行了全面分解，方法论上具有较强的说服力。尽管在用户验证、可达性保证、计算效率和扩展维度等方面仍存局限，该工作仍为多目标 RL 的可解释性与人机交互开辟了有价值的新方向，也为基于“命令干预”的非黑盒解释提供了坚实的基准框架。
