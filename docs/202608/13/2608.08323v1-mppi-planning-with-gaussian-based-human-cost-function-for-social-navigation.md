## 摘要
在拥挤空间中实现安全机器人导航需要规划考虑人们将要去哪里，而不仅仅是现在的位置。模型预测路径积分（MPPI）控制是一种有效的基于采样的规划器，但许多实现将人编码为当前位置的静态点障碍物，低估了动态场景中的风险。我们提出了预测高斯交互场（PGIF），一种时空代价公式，将行人预测在整个规划范围内向前传播，并将其编码为与每个行人运动方向对齐的各向异性高斯排斥场。每个场的前向扩展随行人速度增长，形成运动锥危险区，相比从后方接近的轨迹，更强地惩罚进入行人行进路径的机器人轨迹。该公式为闭式形式，并在所有rollout中完全并行化，不增加可测量的计算开销。在三个密度水平下对300个随机人群场景进行评估，PGIF-MPPI在每个密度水平下实现了0%的碰撞率，而普通MPPI的碰撞率高达82%，同时保持了实时规划性能。

## Abstract
Safe robot navigation in crowded spaces requires planning that accounts for where people will be, not only where they are now. Model Predictive Path Integral (MPPI) control is an effective sampling-based planner, but many implementations encode humans as static point obstacles at their current positions, underestimating risk in dynamic scenes. We propose Predictive Gaussian Interaction Fields (PGIF), a spatiotemporal cost formulation that propagates pedestrian predictions forward over the full planning horizon and encodes them as anisotropic Gaussian repulsive fields aligned with each pedestrian's direction of motion. The forward spread of each field grows with the pedestrian's speed, creating a motion cone danger zone that penalises robot trajectories entering the pedestrian's path of travel more strongly than those approaching from behind. The formulation is closed-form and fully parallelisable across rollouts, adding no measurable computational overhead. Evaluated over 300 randomised crowd scenarios at three density levels, PGIF-MPPI achieves a 0\% collision rate at every density level, compared with up to 82\% for vanilla MPPI, while maintaining real-time planning performance.

## 1. 论文的核心问题与整体含义

- **研究动机**：在拥挤动态环境中，机器人导航的安全性高度依赖于对未来行人运动的预测。现有MPPI规划器大多将行人视为**当前位置的静态点障碍**，忽略其运动方向与速度，导致规划出的轨迹在当前瞬间安全、但在执行时可能与运动中的行人相撞。
- **现有方法的缺陷**：
  - 静态障碍建模会低估动态场景风险，尤其是在过街或汇入场景中。
  - 反应式方法（如SFM、ORCA）缺乏长时域预测，且假设行人主动配合避让，在真实人机交互中常不成立。
  - 深度RL方法隐式编码行人运动，但可解释性差、缺乏安全保证。
  - 已有预测型MPPI（如DRA-MPPI使用离散占用或蒙特卡洛碰撞概率）在行人运动的方向性和速度依赖性上刻画不足。
- **核心问题**：如何在不牺牲实时计算性能的前提下，显式地将行人未来轨迹预测编码进MPPI代价函数，使得进入行人运动路径的轨迹受到更强惩罚？

## 2. 论文提出的方法论

### 总体架构
系统在每步规划周期内依次执行三个模块：
1. **行人状态估计**：提供行人的位置与速度。
2. **PGIF生成器**：将行人预测投影到整个规划时域，生成时间索引的排斥代价场。
3. **MPPI控制器**：采样候选轨迹、评估总代价、输出控制指令。

### 机器人模型
- 使用运动学单圆模型，状态为 `[x, y, ψ, v]`，控制量为 `[v_ref, ψ̇_ref]`。
- 采用半隐式（辛欧拉）积分：先更新朝向角，再用更新后的朝向积分位置。

### MPPI框架
- 参数：`K = 512`条rollout，时域 `T = 40` 步，`Δt = 0.1s`（共4秒规划时域），温度系数 `λ = 1000`。
- 控制约束：速度 `v ∈ [10⁻⁶, 2.0] m/s`，偏航率 `ψ̇ ∈ [-1.5, 1.5] rad/s`。
- 通过重要性加权更新名义控制序列。

### 行人预测
- **直线运动**：使用恒定速度（CV）模型。
- **圆周运动**：使用精确圆运动方程，基于轨道中心、半径、角速度传播位置。
- 预测速度为解析求得，用于确定PGIF的方向。

### PGIF（预测高斯交互场）核心公式
位移分解为平行于行人运动方向和垂直于运动方向的两个分量：

```
d_∥ = (x_ego - h_x) * u_x + (y_ego - h_y) * u_y
d_⊥ = (x_ego - h_x) * n_x + (y_ego - h_y) * n_y
```

各向异性扩展尺度：

```
σ_∥ = 1.2 + 0.5 * s   （当 d_∥ ≥ 0，即行人在前方）
σ_∥ = 0.5             （当 d_∥ < 0，即行人在后方）
σ_⊥ = 0.6             （固定横向扩展）
```

单步代价：

```
C_human = Σ_i exp(-0.5 * ((d_∥/σ_∥)² + (d_⊥/σ_⊥)²))
```

总轨迹代价为四部分加权和：

```
L = w_goal * C_goal + w_term * C_term + w_path * C_path + w_human * C_human
```

权重设为 `w_goal = 1000`、`w_term = 1000`、`w_path = 5000`、`w_human = 10⁶`。

### PGIF的直观特性
- 行人在感知"前方"投影更长的危险区——**运动锥危险区**。
- 前向扩展随行人速度线性增长（`1.2 + 0.5s`），快行人产生更长的前方危险区。
- 后方和侧向受到较小惩罚（0.5m和0.6m扩展），允许机器人从后方接近或侧向绕行。
- 代价为闭式解，可在所有rollout上并行计算。

## 8. 不足与局限

### 保守性问题
- 高密度下成功率仅41%、超时率59%，机器人可能过度等待，实用性受限。
- 没有自适应调节安全权重机制，无法在安全与效率之间动态平衡。

### 成本设计方面
- PGIF是**软代价而非硬约束**，不提供形式化的碰撞避免保证（相比之下CBF或chance-constrained方法有安全保证）。
- 对预测误差没有显式不确定性建模：σ_∥的扩展不随预测不确定性增大。
- 预测模型仅覆盖直线和圆弧两类运动，忽略了行人急停、突然转向、群体交互等真实行为模式。

### 实验验证方面
- 无物理机器人实验，仅仿真验证；真实部署需要感知与追踪管线替代理想的GT行人状态。

- 没有消融实验说明每个设计选择的具体贡献。
- 单一作者、单一仿真环境，结果可泛化性待更多独立验证。

- 超时率指标在Hard档59%意味着"没有碰撞"不等于"有效导航"，整体导航任务完成度仍有限。
