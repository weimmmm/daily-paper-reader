## 摘要
视觉-语言导航（VLN）已从室内环境逐步扩展到室外环境。然而，现有的室外VLN数据集在构建时仍依赖于固定的离散拓扑图。这无法适应快速变化的真实世界室外环境，并阻碍了VLN智能体从仿真到现实的迁移。为解决这一局限，我们提出了DaViNCi（连续环境中的动态视觉-语言导航），这是首个同时引入连续与动态因素的室外VLN数据集。智能体不仅在室外环境中使用连续动作移动，还需要处理不可预测的动态元素。该数据集包含六张不同地图，共6,933条轨迹。通过全面的对比实验，我们发现与先前数据集相比，在离散环境中DaViNCi上的成功率下降了超过10%。而在连续设定中下降幅度更大，这证明了DaViNCi的挑战性。此外，我们阐明了动作粒度与动态元素的影响。这些结果展示了DaViNCi在推动室外VLN迈向更真实环境方面的实用价值。网站为https://xzh0312.github.io/DaViNCi/。

## Abstract
Vision-and-Language Navigation (VLN) has progressively expanded from indoor to outdoor environments. However, existing outdoor VLN datasets still rely on fixed discrete topological graphs for construction. It fails to align with the rapidly changing real-world outdoor environments and impedes the sim-to-real transfer of VLN agents. To address this limitation, we propose DaViNCi (\textbf{D}yn\textbf{a}mic \textbf{Vi}sion-and-Language \textbf{N}avigation in \textbf{C}ont\textbf{i}nuous Environment), the first outdoor VLN dataset that simultaneously introduces both continuous and dynamic factors. The agent not only moves in the outdoor environment using continuous actions but is also required to handle unpredictable dynamic elements. The dataset encompasses six distinct maps with a total of 6,933 trajectories. Through comprehensive comparative experiments, we find that the success rate on DaViNCi decreased by more than 10\% in discrete environments compared to previous datasets. And there is an even greater decline in continuous settings, demonstrating the challenge of DaViNCi. Furthermore, we clarify the impact of action granularity and dynamic elements. These results demonstrate the practical value of DaViNCi in advancing outdoor VLN toward more realistic environments. The website is https://xzh0312.github.io/DaViNCi/.

- **研究背景**：视觉-语言导航（Vision-and-Language Navigation, VLN）任务要求智能体理解自然语言指令、融合视觉观察并完成导航。该领域已从室内逐步扩展到室外场景，但现有室外VLN数据集在环境建模上存在两大根本性缺陷：
  1. **固定离散拓扑图约束**：智能体只能在预先定义的离散节点之间移动，无法体现真实车辆运动的连续性和灵活机动能力（如变道、绕行等），也忽略了具体交通规则。
  2. **完全静态的环境**：同一位置的视觉信息不随时间变化，与真实室外环境中车辆、行人等动态元素频繁交互的现实严重不符。
- **核心问题**：这两大缺陷导致已有VLN方法难以从仿真环境迁移到真实世界的自动驾驶场景，即 **sim-to-real 迁移受阻**。
- **论文回应**：提出 DaViNCi（**Dy**nam**a**mic **Vi**sion-and-Language **N**avigation in **C**ont**i**nuous Environment）数据集，**首次**在户外VLN数据集中同时引入**连续动作空间**与**动态环境元素**两个维度，将数据集的范式从"离散+静态"推向"连续+动态"，从而更准确地刻画真实室外导航环境，推动VLN智能体向实际部署迈进。


## 二、论文提出的方法论（核心思想与关键技术）

### 2.1 核心思想

设计一套能够**在连续动作空间中导航、并实时应对动态障碍物**的户外VLN数据集构建及评测框架，使智能体在导航过程中不仅依赖固定的预采集图像，而是基于仿真器的实时渲染输出做出连续决策。

### 2.2 数据集构建方法（CARLA 模拟器）

**（1）场景选择**
- 选取CARLA中6张地图：`town01`、`town02`、`town03`、`town04`、`town05`、`town10`，覆盖乡村、城镇、高速、城市等不同场景类型。
- 参考CARLA AD Leaderboard设计多种交通情景：红绿灯与交通标志处理、信号/非信号交叉口通行、环岛通行、变道等。

**（2）路径生成**
- 在无动态障碍物的环境中，初始化随机自动驾驶车辆自由行驶，采集车辆每秒的位置信息，连接成 ground-truth 路径。
- 6张地图的路径分布为 `{town01: 969, town02: 765, town03: 930, town04: 463, town05: 951, town10: 2855}`，总计6,933条轨迹。

**（3）指令生成与对齐**（双阶段框架）
- **第一阶段（数学量化）**：基于轨迹数据精确提取转向事件（作为先验约束）。
- **第二阶段（视觉语义生成）**：录制第一人称驾驶视频，输入给视觉语言模型（VLM / Qwen3），通过提示词约束（严格遵循转向方向、仅输出导航格式、提取真实地标、区分转弯与弯道）生成结构化导航指令。
- 最后由人工微调，确保指令在逻辑上与地标细节上和视觉信息对齐。

**（4）视觉信息获取**
- 克服以往数据集"固定拓扑图+预采集全景图"的静态模式，在导航过程中按需实时渲染第一人称视角图像，满足动态环境需求。

**（5）动态元素注入**
- 在每次实验中随机注入行人与车辆等动态实体，其行为由程序化规则驱动且具有随机性，使得即使沿同一路径行驶，智能体面临的观测也各不相同。

**（6）质量控制**
- 使用统一LLM与提示模板保证标注一致性；人工筛查逻辑不一致或描述不合理的文本；剔除发生碰撞或违反交规的路径实例，最终保留6,933条高质量路径-指令对。

### 2.3 连续环境下的基线方法：COVL-RL

论文提出了一个**上下文感知的在线视觉-语言强化学习框架（Context-aware Online Vision-Language RL, COVL-RL）**，以适配DaViNCi的连续动态设置。其核心要素为：

- **状态表示**：智能体状态为空间坐标 `p = (x, y, z) ∈ R³` 与姿态角 `(θ, ϕ)`；每步由CARLA根据当前状态渲染 1280×720 第一视角RGB图像。
- **动作空间**：`A ∈ {sharp left, left, straight, right, sharp right, lane change, stop}`，其中转向动作直接驱动车辆向指定方向前进（区别于传统原地旋转），且受实时路况约束以保证交通规则合规。
- **策略建模**：
  \[a_t \sim \pi_\theta(a_t \mid I, H_t, V_t)\]
  其中 `I` 为语言指令，`V_t` 为当前视觉观测，`H_t = {V_1, A_1, V_2, A_2, ..., V_{t-1}, A_{t-1}}` 为历史轨迹上下文。
- **实现流程**：CLIP提取视觉/文本特征 → Transformer编码 → LSTM聚合历史 → Linear输出动作分布 → 与模拟器交互获取奖励并更新策略。


## 三、实验设计（数据集、Benchmark 与对比方法）

### 3.1 离散环境实验

**目的**：验证数据集的有效性并量化其挑战性。

- **离散化处理**：选取 `town01、town02、town03、town10` 四张地图，按Touchdown数据集格式构建离散拓扑图。其中 town01/town02/town10 采用5米细粒度，town03 采用12米粗粒度（与先前数据集相似）。
- **划分**：每张图按约 8:1:1 划分为训练/验证/测试集。
- **评估指标**：TC（任务完成率）、SPD（最短路径距离）、nDTW（归一化动态时间规整）。
- **对比方法**：GA (2019)、Rconcat (2019)、VLN-trans (2021)、ORAR (2022)、VELMA (2024)、VELMA+Mem4Nav (2025)、FLAME (2025)、FLAME+Mem4Nav (2025)，并与 Touchdown 和 Map2Seq 数据集上的表现进行横向对比。

### 3.2 连续环境实验

**目的**：在连续动态环境中验证方法性能，分析关键影响因素。

- **划分**：仅用 `town10` 作为训练环境（约6:1:1划分），其余5张地图作为完全未见的测试场景，考验模型泛化能力。
- **评估指标**：平均导航误差 ANE（m）、成功率 SR（终点10米半径内）、平均路径完成率 APC。
- **对比方法**：COVL-RL 基线 vs. 两种随机策略（纯随机；随机但无stop并靠偏离检测程序终止）。
- **消融实验**：
  1. **动作粒度**：3m、4m、5m 三档步长对比。
  2. **动态元素数量**：无动态元素、10车+10行人、30车+30行人三档对比。

## 六、论文的主要结论与发现

1. **数据集有效性**：在离散环境下，已有VLN方法在DaViNCi上仍能达到 TC≈28.9%~40.7%（不同地图），说明指令-视觉对齐质量合格，数据集不是不可解。
2. **数据集挑战性**：
   - 相比Touchdown/Map2Seq，各方法在DaViNCi上的成功率普遍下降**超过10%**；
   - 连续动态环境下成功率进一步显著下降（基线SR约为12%~18.2%，随机算法趋近于0），证明"连续+动态"双因素对VLN任务构成重大挑战。
3. **动作粒度对性能影响有限**：3m/4m/5m三档步长下性能差异不显著，说明细粒度增加的信息量与粗粒度的步数减少之间存在一种折中，影响呈非线性。
4. **动态元素显著降低性能**：随着动态元素数量增加（0→10→30），SR与APC持续下降，原因在于动态遮挡干扰了智能体的部分视野，要求其适应不完整的视觉输入。
5. **泛化挑战**：模型在未见图（town01~05）上的性能普遍低于训练图（town10），且不同地图间差异明显，说明从单一地图训练后泛化到新场景仍是难题。


## 七、优点（方法与实验设计的亮点）

1. **首个"连续+动态"户外VLN数据集**：填补了现有室外VLN数据集在连续动作与动态元素方面的空白，是面向真实自动驾驶场景的重要一步。
2. **可视数据实时渲染而非预采集**：使同一路径在不同试次中呈现不同观测，更贴近真实世界的非平稳性。
3. **指令生成采用"轨迹量化先验 + VLM语义生成 + 人工微调"流水线**：有效克服了VLM从第一人称驾驶视频生成导航指令不稳定的问题，同时用轨迹数据保证转向描述的准确性。
4. **提供两套评测基准（离散+连续）**：离散实验便于与历史方法对比，连续实验则面向未来更具实际价值的研究方向。
5. **进行了关键因素的消融分析**：明确量化了动作粒度与动态元素数量对任务性能的影响，为后续研究提供了有价值的参考依据。
6. **设计了公平的随机基线**：区分有无stop动作的随机策略，从对照角度凸显了数据集的难度与基线的有效性。
7. **手动质量控制**：人工筛选不一致指令、剔除违规路径，保障了数据质量。


## 八、不足与局限

1. **仿真环境偏差**：所有数据均来自CARLA模拟器，视觉风格、物理规律和动态行为与真实世界仍有差距，数据集的"逼真度"缺乏真实的户外实测验证。
2. **连续环境实验覆盖有限**：只提出了一个连续基线（COVL-RL），缺少与其他连续VLN方法（如VLN-CE上的代表性模型）的系统对比，削弱了连续环境下结论的普适性。
3. **训练场景单一**：连续实验仅使用 town10 作为训练环境，训练/测试地图风格差异大（如纯乡村、高速公路），模型可能因地图域差异过大而表现不佳，而非仅因"连续+动态"因素。
4. **缺少多随机种子与统计显著性检验**：未报告方差，无法判断方法间差异及不同实验条件差异的显著性。
5. **指标局限**：连续环境引入了ANE/SR/APC，但未涉及交通规则违反率、碰撞率等对自动驾驶十分关键的指标；离散环境指标也无法反映连续控制的平滑性与安全性。
6. **指令生成本身可能引入偏置**：使用同一LLM和提示模板可能使指令风格和措辞模式单一化，倾向于LLM的典型表达方式，对模型的文本理解泛化可能有潜在影响。
7. **算力信息不完整**：连续实验部分未说明训练资源、时长和超参数细节，复现门槛较高。
8. **数据集规模与真实户外数据相比有限**：6,933条轨迹虽然覆盖多种场景，但与真实城市级数据（如Touchdown的2.9M总长度）相比仍有差距，需进一步扩展。
