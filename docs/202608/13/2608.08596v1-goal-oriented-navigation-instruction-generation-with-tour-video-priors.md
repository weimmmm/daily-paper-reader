## 摘要
导航指令生成（NIG）旨在为导航引导生成逐步的自然语言指令。现有研究主要将NIG视为视觉语言导航（VLN）的辅助任务，关注数据增强或多任务学习。然而，从紧凑的环境先验中生成导航指令需要精细的空间推理，尤其是当目标路线并非简单地遵循演示游览路线时，这对当前多模态模型仍具挑战性。在本工作中，我们引入VideoNIG，一种目标导向的视频基础NIG任务，从以自我为中心的游览视频、初始观察以及文本或视觉目标中生成导航指令，无需依赖图或地图等中间表示。我们在一个受控模拟器基准中实例化VideoNIG，包含连续室内环境中的6万段游览视频和3.7万个具有渐进难度级别的多模态提示。我们进一步引入一种诊断性评估协议，结合文本相似性、基于选择的空间一致性测试以及下游导航执行。为解决此任务，我们提出一个两阶段课程学习框架，将学习分解为基础运动感知和长时程导航推理。具体而言，我们首先采用动作预热进行空间动作视角对齐，随后使用探索难度递增的轨迹进行复杂度递进。大量实验表明，现有多模态大语言模型（MLLM）难以应对VideoNIG，而我们的方法在互补的诊断指标上显著提高了指令质量。最后，将VideoNIG生成的指令与VLN代理集成，证明了该任务公式对端到端导航的可执行性。

## Abstract
Navigation Instruction Generation (NIG) aims to produce step-by-step natural language instructions for navigation guidance. Existing studies primarily treat NIG as an auxiliary task for vision-andlanguage navigation (VLN), focusing on data augmentation or multi-task learning. However, generating navigation instructions from compact environmental priors requires meticulous spatial reasoning, especially when the target route does not simply follow the demonstrated tour, and remains challenging for current multimodal models. In this work, we introduce VideoNIG, a goal-oriented video-grounded NIG task that generates navigation instructions from ego-centric tour videos, an initial observation, and a textual or visual goal, without relying on intermediate representations such as graphs and maps. We instantiate VideoNIG in a controlled simulator benchmark with 60K tour videos across continuous indoor environments and 37K multimodal prompts with progressive difficulty levels. We further introduce a diagnostic evaluation protocol that combines text similarity, choice-based spatial consistency tests, and downstream navigation execution. To address this task, we propose a two-stage Curriculum Learning framework that decomposes the learning into foundational motion perception and long-horizon navigation reasoning. Specifically, we first employ Action Warmup for spatial action-view alignment, followed by Complexity Progression using trajectories with increasing exploratory difficulty. Extensive experiments show that existing MLLMs struggle with VideoNIG, while our approach significantly improves instruction quality across complementary diagnostic metrics. Finally, integrating VideoNIG-generated instructions with a VLN agent demonstrates the executability of this task formulation for end-to-end navigation.

- **核心问题**：能否利用**第一视角游览视频（ego-centric tour video）**作为紧凑、视频原生的环境先验，在只有简单目标描述（文本或图像）和初始观察的情况下，自动生成可执行的全局导航指令？

## 2. 方法论

### 2.1 总体框架：两阶段课程学习（Curriculum Learning）

作者认为，直接在复杂长视频上训练指令生成会导致优化不稳定。为此，将学习过程分解为两个维度：

- **Stage 1：动作预热（Action Warmup）**
  - 目标：建立基础空间感知与动作-视图对齐能力。
  - 两个子任务：
    - **Action-from-View**：给定初始帧和后续帧，预测相对相机运动（如“前进 100 cm”“左转 30°”），动作空间共 13 种（平移距离、旋转角度、停止）。
    - **View-from-Action**：给定初始帧和动作指令，从 4 个候选帧中选择正确的结果帧。
  - 训练使用 GRPO，奖励设计为分层奖励：对动作类型、角度/距离的邻近程度给予不同得分，惩罚类型混淆。

- **Stage 2：复杂度递进（Complexity Progression）**
  - 训练数据按照轨迹复杂度顺序引入：**Gold Route → Tyro Tour → Curiosity Tour → Explorer Tour**，从低难度到高难度渐进学习，避免一步到位导致的空间推理崩溃。
  - 优化方法支持两种：
    - **GRPO（Group Relative Policy Optimization）**：奖励函数由四部分组成：
      - 指令相似性（SPICE + Rouge-L）
      - 语言质量（LLM judge 评估）
      - 轨迹一致性（MLLM 根据 Gold Route 视频和生成指令评估）
      - 长度惩罚（防止冗余）
    - **MPO（Mixed Preference Optimization）**：利用负样本（基于评估协议构造的方向、实体、子路径篡改）进行偏好优化，并通过 SFT + LoRA 进一步微调稳定生成。

### 2.2 Benchmark 构建流程

- 基于 Habitat 模拟器和 R2R-CE、RxR-CE 数据集渲染视频。
- 生成四类视频：
  1. **Gold Route**：最优路径视频；
  2. **Tyro Tour**：在最优路径两端随机扩展少量步数；
  3. **Curiosity Tour**：加入环顾、邻域访问等轻度探索；
  4. **Explorer Tour**：大幅偏移路点，重叠度低，难度最高。
- 质量筛选：
  - 移除 nDTW < 0.8 的非最优路线；
  - 用 Z-score、RANSAC、Isolation Forest 集成异常检测，过滤指令词数与动作序列长度不一致的样本；
  - 用 qwen3-vl-plus 生成起点/目标描述，并通过文本-图像、图像-图像相似度过滤非判别性描述。

## 3. 实验设计

### 3.1 数据集与场景

- **基础数据**：R2R-CE 和 RxR-CE，在 Habitat 模拟器的连续室内环境中。
- **视频规模**：约 20K Gold Route 视频、60K 游览视频（含 Tyro/Curiosity/Explorer）、37K 多模态起始-目标描述（图像/文本）。
- **难度分级**：Gold Route 最简单，Explorer Tour 最困难（轨迹更长、偏转更多、转向频繁）。
- 评估协议三种：
  1. **文本相似度**：Rouge-L、SPICE；
  2. **选择评估（Choice Evaluation）**：Multiple-choice（五种负样本：方向替换、实体替换、删除、添加、交换）和 Orthogonal-choice（仅方向/实体替换，避免文本捷径），衡量空间一致性；
  3. **导航执行**：将生成指令输入 InternVLA-N1 VLN 代理（System2 和 Dual System 配置），评估 SR、SPL、OS、NE、nDTW。

### 3.2 对比模型

- 开源模型：InternVL3-8B、InternVL3.5-4B/8B、Qwen2.5-VL-7B、Qwen3-VL-4B/8B。
- 专有模型：gpt-5.2-chat、qwen3-vl-plus。
- 方法变体：Qwen3-VL-8B 的 SFT、GRPO、MPO、MPO-lora。

### 3.3 实验数量与充分性

- **主实验**：在 4 种视频类型 × 2 个数据源（R2R/RxR）× 2 种目标模态（图像/文本）= 16 种配置下评估。
- **消融实验**：
  - 链式思考（CoT）有无；
  - 课程学习两阶段（Action Warmup、Complexity Progression）逐一去除。
- **额外实验**：VSI-Bench 相关性分析、下游导航执行（8 种模型/方法 × 2 种系统配置 × 4 种视频类型）。
- 实验规模较大、覆盖较完整，比较对象包括开源与闭源模型，评估维度多样。

## 5. 主要结论与发现

1. **VideoNIG 对现有 MLLM 极具挑战性**：InternVL3.5、Qwen3-VL 等强模型在文本相似度和选择评估上均表现一般，且复杂度越高性能下降越明显。
2. **选择评估比文本相似度更能反映导航性能**：Multiple-choice 和 Orthogonal-choice 与 VLN 成功率（SR）的相关性显著高于 Rouge-L 和 SPICE（图 5）。
3. **课程学习有效**：两阶段课程学习（Action Warmup + Complexity Progression）显著提升指令质量与空间一致性，且单独使用任一阶段效果有限。
4. **MPO 优于 GRPO**：在导航执行任务中，MPO 训练的模型（尤其是 MPO-lora）在 SR、SPL 上优于 GRPO，因其兼顾语言风格和空间逻辑；GRPO 在文本相似度上更高是因为其奖励函数直接优化了这些指标。
5. **LoRA 导致模仿偏差**：LoRA 微调模型容易模仿指令风格而非内化空间结构，在下游导航中性能反而低于全参数微调。
6. **与通用空间智力正相关**：VideoNIG 表现与 VSI-Bench 得分正相关，说明任务依赖基础空间推理能力。
7. **VideoNIG 可执行性验证**：生成的指令可以驱动 VLN 代理完成导航，虽然与人工指令仍有差距，但验证了“视频先验 → 指令 → 导航”的端到端范式可行。

## 6. 优点

- **任务新颖且有价值**：提出以游览视频作为环境先验的目标导向 NIG 任务，跳过了图/地图等显式表示，更贴近实际用户需求。
- **基准构建严谨**：多级复杂度视频、多模态目标、严格的异常检测和判别性过滤，保证了数据质量。
- **评估协议全面**：不只使用文本相似度，还设计了选择式空间一致性测试和真正的下游导航执行，更贴近实际效用。
- **方法设计合理**：两阶段课程学习分解了“局部动作感知”和“长时程推理”，训练稳定，可解释性强。
- **诊断洞察丰富**：通过相关性和消融分析明确了各指标的有效性、LoRA 的局限以及 MLLM 在长视频空间推理上的薄弱环节。

## 7. 不足与局限

- **模拟器限定**：所有视频和评估均在 Habitat 室内连续环境模拟器中完成，未涉及真实世界 tour 视频；作者也承认这一点，不覆盖自然采集视频和社会导航场景。
- **指令分布约束**：Gold Route 视频基于人工标注的 R2R/RxR 路径，指令风格与人类注释高度绑定，可能导致模型对特定语言风格的过拟合。
- **目标描述依赖自动生成**：起始/目标描述由 qwen3-vl-plus 生成，可能存在描述噪声或表达偏好，影响评测公正性。
- **导航执行仍有明显差距**：生成指令在复杂 tour（Curiosity/Explorer）下 SR 很低，且始终低于人工指令；VLN 代理本身对指令风格的分布偏差敏感。
- **算力资源未完全说明**：部分细节（如 LoRA 的 GPU 数量、具体功耗等）未披露，可复现性略受影响。
- **扩展性有限**：视频帧采样上限 210 帧，对更长路线或更高帧率视频的处理能力尚不清楚；没有探索多语言或跨文化场景。

## 8. 总结定位

VideoNIG 是一项扎实的基准+方法研究，重新定义了“有环境先验的导航指令生成”，并指出当前 MLLM 在长时程视频空间推理上的不足。其课程学习框架和诊断评估协议为后续工作提供了新思路，但受限于模拟环境和指令分布，距离实际应用仍有较大距离。
